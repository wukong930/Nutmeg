# Nutmeg PRD 产品需求文档 v2

## 1. 产品概述

### 1.1 产品名称

**Nutmeg**

名字简短、有足球感。“Nutmeg” 是足球里的穿裆动作，适合一个有趣但专业的预测工具。

### 1.2 产品定位

Nutmeg 是一个长期使用的足球比赛单场概率预测与组合分析平台，目标是为用户提供：

```text
每场比赛的胜平负概率
让球玩法概率
比分概率
冷门风险
串关组合分析
预测解释
模型历史表现
```

Nutmeg 不以“保证盈利”或“自动下注”为目标。产品核心目标是：

> 通过数据、模型、市场基准、错误学习闭环，持续提升足球比赛预测准确性。

### 1.3 产品一句话

```text
Nutmeg turns every football match into a probability map.
```

中文表达：

```text
Nutmeg 把每场足球比赛变成一张可解释、可回测、可迭代的概率地图。
```

## 2. 用户与场景

### 2.1 目标用户

| 用户类型 | 诉求 | Nutmeg 提供 |
|---|---|---|
| 普通球迷 | 想看比赛前景 | 胜平负、比分倾向、关键因素解释 |
| 数据分析爱好者 | 想看概率和模型表现 | 比分矩阵、校准、回测、市场对比 |
| 内容创作者 | 需要赛前分析素材 | 冷门榜、热门脆弱度、图卡式解释 |
| 竞彩/赔率研究者 | 需要玩法概率和串关组合评估 | 让球、亚洲盘、串关、复式成本、EV、ROI |
| 产品/运营人员 | 需要长期赛事覆盖 | 配置化赛事接入、模型状态、数据质量 |

### 2.2 使用场景

#### 场景 A：查看今天比赛预测

用户打开首页，看到：

```text
今日比赛列表
每场胜平负概率
模型置信度
市场差异
冷门提示
数据更新时间
```

#### 场景 B：查看单场详情

用户点击一场比赛，看到：

```text
比分概率矩阵
胜平负概率
中国竞彩让球胜平负
亚洲让球概率
比分 Top 5
关键影响因素
赔率变化
模型与市场差异
历史类似比赛表现
```

#### 场景 C：寻找冷门

用户进入冷门榜，看到：

```text
热门不胜风险
热门输盘风险
弱队受让概率
低比分/平局倾向
冷门原因
风险等级
```

#### 场景 D：生成二串一、三串一、四串一

用户选择：

```text
预算
关数
风险偏好
玩法范围
是否允许复式
```

系统输出：

```text
稳健组合
价值组合
冷门观察组合
高波动组合
每个组合的注数、金额、命中概率、EV、ROI、风险解释
```

#### 场景 E：开发者查看模型是否变准

内部用户进入 Accuracy 页面，看到：

```text
模型版本对比
Log Loss / Brier Score
校准曲线
联赛分层表现
错误类型分布
新模型是否允许上线
```

## 3. 产品范围

### 3.1 MVP 首发功能

#### F1. 比赛列表

- 支持按日期、赛事、联赛筛选。
- 展示主客队、开赛时间、模型状态、胜平负概率、冷门标签。
- 每场比赛必须显示 `prediction_time` 和 `model_version`。

#### F2. 单场预测详情

必须包含：

```text
1X2 胜平负概率
中国竞彩让球胜平负
亚洲让球主盘口
比分 Top 5
比分矩阵简化视图
总进球倾向
双方进球倾向
市场概率对比
关键因素解释
数据质量标签
```

#### F3. 冷门风险识别

冷门类型包括：

```text
favorite_fail_to_win       热门不胜
favorite_loss              热门输球
underdog_cover             弱队受让赢盘
favorite_fail_to_cover     热门赢球但输盘
draw_overlooked            平局被低估
low_score_trap             小比分陷阱
blowout_tail_risk          大比分尾部风险
```

#### F4. 串关组合优化

支持：

```text
2串1
3串1
4串1
复式串关
多选项展开
成本计算
规则合法性校验
组合命中概率
EV / ROI
风险等级
```

MVP 不做自动下单。

#### F5. 模型表现页面

支持查看：

```text
按模型版本
按联赛
按玩法
按时间窗口
按赔率区间
按冷门类型
```

指标包括：

```text
Log Loss
Brier Score
Calibration Error
Top-1 Accuracy
Upset Precision@K
Closing Odds Comparison
```

#### F6. 赛事扩展配置

后台/配置文件支持新增赛事：

```text
国内联赛
国内杯赛
洲际俱乐部赛事
国家队赛事
```

新增赛事不应修改核心模型代码。

## 4. 详细需求

### 4.1 比赛预测卡片

#### 字段

```text
fixture_id
competition_name
kickoff_time_local
home_team
away_team
p_home
p_draw
p_away
market_p_home
market_p_draw
market_p_away
model_edge_summary
upset_badge
confidence
model_version
prediction_time
```

#### 展示规则

- 概率保留 1 位小数。
- 不使用“稳胆”“必中”“包中”等表达。
- 如果模型状态为 Beta，必须显示 Beta 标签。
- 如果数据质量低，概率区域要显示提示。

### 4.2 单场详情页

页面模块顺序：

```text
1. 比赛头部
2. 胜平负概率
3. 市场对比
4. 让球玩法
5. 比分倾向
6. 冷门分析
7. 关键因素
8. 赔率/盘口变化
9. 类似预测历史表现
10. 模型元信息
```

### 4.3 比分预测

不展示单一确定比分，而展示：

```text
比分 Top 5
竞彩比分选项概率
胜其它 / 平其它 / 负其它
大比分风险
长尾比分概率
```

示例：

```text
比分倾向：
1-1：11.8%
1-0：10.3%
2-1：9.5%
0-0：8.2%
0-1：7.6%

尾部事件：
主队 3+ 球大胜：6.1%
客队 3+ 球大胜：2.4%
任一方 4+ 球：1.3%
```

### 4.4 冷门榜

冷门榜不是“爆冷推荐”，而是“热门风险雷达”。排序因子：

```text
模型与市场差异
热门脆弱度
盘口偏深程度
阵容/赛程风险
平局概率偏高
低比分倾向
弱队受让概率
赔率异常变化
```

必须展示冷门方向：

```text
热门不胜
弱队受让
让球平/让球负
平局被低估
强队小胜陷阱
```

### 4.5 串关推荐页

支持三种入口：

```text
系统自动推荐
用户选择候选后系统优化
复制/手动录入选项后评估
```

#### 用户参数

```text
预算
单注金额
关数范围
风险偏好
玩法类型
是否允许复式
最大注数
是否允许冷门腿
是否排除 Beta 赛事
```

#### 输出

每个组合展示：

```text
组合类型
选择选项
注数
总金额
组合命中概率
理论返还
预期返还
EV
ROI
风险等级
推荐理由
不确定因素
规则合法性
```

## 5. 非功能需求

### 5.1 准确性

所有预测都必须可回测。任何页面显示的概率都必须能追溯到：

```text
model_version
feature_version
calibration_version
prediction_time
input_data_snapshot
```

### 5.2 可扩展性

新增联赛/赛事时，必须走配置化接入，不得写死五大联赛。

### 5.3 可解释性

每个主结论必须至少有一组解释：

```text
模型因素
市场因素
阵容/赛程因素
风险因素
```

### 5.4 合规性

- 不实现自动下注。
- 不承诺收益。
- 不使用“稳赚”“必中”之类表达。
- 不面向未成年人。
- 对涉及投注金额的页面显示风险提示。
- 遵守数据源授权条款。

## 6. 验收标准

### MVP 验收

- 可以导入至少 1 个赛季历史赛程/赛果。
- 可以生成比赛预测快照。
- 可以生成比分矩阵。
- 胜平负、竞彩让球、亚洲让球概率由比分矩阵派生。
- 可以展示比赛列表和单场详情。
- 可以生成二串一/三串一/四串一和复式组合。
- 串关模块可以计算注数、金额、命中概率、EV、ROI。
- 可以记录赛后结果并计算 Log Loss / Brier Score。
- 可以生成模型版本报告。
- 所有核心模块有单元测试。

### 准确性验收

MVP 不要求马上超过市场，但必须达到：

```text
概率总和正确
比分矩阵归一化
玩法派生规则正确
回测无数据泄漏
概率校准可视化可用
模型表现可按联赛和玩法分层
```

## 7. 产品边界

Nutmeg 可以提供：

```text
概率预测
风险分析
组合评估
历史表现
解释性分析
```

Nutmeg 不提供：

```text
自动投注
保证收益
资金代管
下注执行接口
诱导性赌博文案
```
