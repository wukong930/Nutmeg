💰 投注规则

项目取值含义
起投单位— 单注最低金额，必须是该数的整数倍 (¥2 起投, 倍数限制)
单注上限— 每张票最大金额，超过则系统拒单
串关下限— 混合过关最少串关数 (2 串 1 起)
串关上限— 混合过关最多串关数 (8 串 1 封顶)

🎲 派奖机制

项目取值含义
派奖率— 平均派奖比例，¥1 投注长期回收 = 派奖率 × ¥1
庄家抽水 (vig)— = 1 - 派奖率。对比 Pinnacle 体育博彩 vig ≈ 2.5%，竞彩高出 ~12x

✅ 推荐门槛

项目取值含义
最小 EV/单位— 票面 EV 低于此值则不推荐 (5% = 模型相对庄家盘口的安全边际)
最小命中率— 低命中率 + 高赔率 = 高方差，默认筛掉
凯利分数0.25 部分凯利 (1/4 倍) 防止模型误差导致的过激加仓
单注预算占比≤ 5% 单张票最高占预算 5%，避免单次重仓

📋 玩法说明

玩法说明
胜平负 (1X2) 不带让球，单纯判断主队胜 / 平 / 客队胜
让球胜平负 带整数让球数 (如 -1 = 主队让一球)；按让球后的比分判定胜平负
浮动让球 让球数在下单瞬间锁定 (SP 同步锁定)，与赛前其他时间无关
浮动 SP 赔率在下单瞬间锁定，竞彩平台显示的为参考值
单关 单场比赛，单注最低 ¥2，命中即返奖
串关 (混合过关) 2 ~ 8 场比赛全部命中才返奖，赔率累乘
复式 选 M 场预测 + N 串 1，下注全部 C(M,N) 张子票

⚠️ 风险提示

  • 本系统仅提供 参考 推荐，从不自动下单。所有票请人工到竞彩终端复核 SP 后再下注。
  • 派奖率 68.5% 意味着即使是 +5% EV 的推荐，仍有较大方差；请用闲置资金、固定预算。
  • 建议每周用②录入结果 + ③ROI 报告 复盘，连续 4 周 ROI 负值时停手复盘模型。
  • 未成年人请勿购买，理性投注。
