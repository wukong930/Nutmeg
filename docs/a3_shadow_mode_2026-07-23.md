## 1. 病灶:门槛用的 σ_P 是个**单点常数**

`threshold(P) = base + z·σ_P·lf·SP`,而 σ_P 一直钉死 **1.2pp**。
A-1(`docs/freeze_gap_measurement_2026-07-18.md`)测出的其实是条**曲线**:
σ_P(h) = A·h^B(主 0.0079/0.31 · 平 0.0042/0.23 · 客 0.0077/0.27)。

钉死值落在曲线的哪里?**h ≈ 4h**:

| h | 主 σ_P | vs 钉死 1.2pp |
|---|---|---|
| 0.5h(下界) | 0.64pp | **低了一半** |
| 2h | 0.98pp | 低 |
| **4h** | **1.21pp** | ≈ 持平 |
| 6h | 1.38pp | 高 |
| 24h | 2.12pp | **高了 77%** |

⇒ 钉死值让**凌晨场(缺口 6h+,占 41%)的门槛系统性偏低**、**临近开球偏高**。
两个方向都错,只是错的号相反 —— 这类偏差不会互相抵消,它按场次分布挑人。

> ⚠️ **顺手发现一处两次测量对不上,未调查**:`ev_threshold.py` 原注(06-26)把
> 1.2pp 归给「12-24h 冻结缺口」,但 A-1(07-18,直接拟合 75 条线史轨迹)的曲线在
> 12-24h 给 **1.7-2.1pp**,1.2pp 落在 **h≈4h**。本次按新压旧取 A-1,
> **但这个分歧本身没查过** —— 可能是 06-26 的缺口口径偏小,也可能是两边样本不同。
> 记在这里,免得日后有人把两个数字当同一次测量互相引用。

## 2. 修法:让门槛和 ± 带**共用同一个 σ**

A-2 已经把 σ_P(h) 做成了显示用的 ± 带(`_frzHalfEv` 返回 2σ_P(h)·SP)。
所以门槛这侧**不需要再算一遍** —— 直接吃 `半宽/2`:

```
threshold = base + z·lf·(frzHalf/2)
```

这比"再抄一份系数表"强的地方在于:**冻结那一份不确定性物理上只有一个来源**。
若哪天改了系数,± 带和门槛一起动;抄两份则留了个只改一半的口子。

> ⚠️ **让球行是个有意的例外**:那里的 ± 带是 `δ ⊕ 冻结` 的平方和,而门槛**只吃冻结那半**。
> 因为 δ(让球重构的校准误差)已经由 A′ 的下界 `evLo` 判过一次闸,再进门槛就重复计。
> 所以让球行的 ± 会**比门槛所隐含的宽** —— 这不是 bug,是两者管的事不同。

拿不到开球时刻的老调用点传 `null` → 回落钉死 1.2pp × 公允 SP,
**与改动前逐位相同**(有测试锁)。

同步落在三处,`tests/v4/test_ev_threshold.py::test_frontend_mirrors_the_same_coefficients`
直接读 `dashboard.html` 断言系数与 `MIN_HOURS` 一致 —— 前后端漂开会红。

### 实际效果(P=40%、SP=2.5 的同一注)

| h | 主 | 平 | 客 |
|---|---|---|---|
| 0.5h | 6.6% | 5.9% | 6.6% |
| 4h | **8.0%**(≈ 旧值) | 6.4% | 7.8% |
| 24h | **10.3%** | 7.2% | 9.5% |

_(Python 与 JS 两侧 15 格逐位相同,已实测对表。)_

## 3. 回放:**没测出结论,原因有三个**

`scripts/shadow_a3_threshold.py` 在 `jingcai_sp` 上重放新旧门槛。
**不需要新建表** —— 该表已存回放所需全部输入(SP=`jc_*` · P=`psc_*` 走 WPO ·
h=`kickoff_utc`−`captured_at` · 结果=`ft_outcome`)。少一条写入路径 = 少一处会漂。

结果:**新旧门槛判定反转 0 / 144 腿**。这个 0 **不是"两者等价"**,是三重无能:

| 原因 | 证据 | 什么时候消失 |
|---|---|---|
| ① **样本被配额耗尽期打空** | 223 行里 **169 行缺 `psc_*`**,可用仅 48 行 | odds cron 已于 07-22 恢复,秋季自然积累 |
| ② **回放的 h 分布错位** | 我们的 SP 抓取集中在停售前后,**h 中位仅 0.5h**;而本次修的正是 6-24h 那段 | 需要在**更早**的时点也留 P 侧快照 |
| ③ **根本没有腿够得着任何门槛** | 144 腿中仅 **1 腿**过平 5%(还是个走运的冷门) | 得先有 +EV 腿(见 `记忆 soft-water-leg-finding-measured` 的 0/33) |

②尤其值得记住:**回放采样不到它要修的那个区间**。门槛差在 h<2h 是 −2.2pp、
在 6-24h 只有 −0.1pp,而 2/3 的样本落在前者 —— 这份回放主要在丈量一个不重要的角落。

## 4. 诚实边界

1. **这是显示层改进,不是赚钱改进。** 它让"离开球还早"这件事在面板上可见,
   **没有增加任何 +EV 腿**,也没改变任何推荐
2. **σ_P(h) 只覆盖 P 侧。** SP 侧(竞彩自己调价)另有分布,未合成进这个带
3. **A-1 曲线本身有 ~15% 拟合偏差**(75 条自家轨迹 + 25,886 场交叉验证)。
   h=24 外推到 h=168(封顶)已属外推,别当精确值读
4. **让球腿借用主胜曲线**(三条里最宽 = 保守),不是它自己的测量值
5. **"0 反转"来自空样本,不是来自等价性** —— §3 那张表就是防止半年后有人
   把这个 0 引用成"A-3 没用"
