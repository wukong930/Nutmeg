# 三方回测:Pinnacle 亚盘直读 vs DC 网格重构(竞彩 3 路让球)

_2026-07-04 · 只读测量,零 API 调用,零生产改动 · 脚本一次性(scratchpad),方法记录于本文_

## 问题

Pinnacle 的让分盘(亚盘)对竞彩 3 路让球有没有**反推计算意义**?即:放着实盘亚盘价不用、
用 1X2+O/U 拟合 DC 网格再切净胜球,是不是绕远路?

两个先验(都已有测量,但都不在**结果空间**直接对决过):

- 2026-06 价格空间:Pinnacle 亚盘价可由 1X2+O/U 网格复现(当时的 "4pp 差异" 是**四分之一线
  评估 bug**,非真差异)→ 冗余。
- 10k 场回测:网格重构让球对 ≤92% 热门校准良好(轻微高估热门);**95%+ 区间未测**。

悬而未决的第三问:**让平腿**。亚盘直读免模型,但让平 = 两条相邻半球线去 vig 累积概率的
**差值**——两团噪声相减;网格让平 = 模型内在一致的单一质量。谁的误差小,只能用真实赛果裁。

## 方法

对缓存中每场已结束、带 Pinnacle 报价的比赛,取整数让球线 h ∈ [−3, +3],要求相邻两条
**纯半球线** (h−½, h+½) 都被实盘报价(四分之一线一律排除——规避已记录的评估陷阱):

| 方法 | 让胜 | 让平 | 让负 |
|---|---|---|---|
| **亚盘直读** | devig(h−½) 主方 | devig(h+½) − devig(h−½) | 1 − devig(h+½) |
| **网格重构** | 1X2(WPO 去vig)+O/U(**真实盘口线**,basic 去vig)→ `fit_lambdas` → DC 比分网格 → 净胜球 pmf,P(margin>−h) / P(=−h) / P(<−h) | | |

两法读**同一个赔率快照**(同一信息集,公平对决)。结算:90' 比分(score.fulltime 优先),
`diff = (hg+h)−ag` → 让胜/让平/让负。指标:3 路 log-loss / Brier,**按场自举**(同场多线相关,
4000 次重采样)配对差 95% CI;按热门度(1X2 去vig 最大方)分桶;让平腿单独校准;
按两法分歧幅度分桶归因。

## 数据

- 已结束带比分:**15,010** 场;其中带 Pinnacle 1X2 + 可用纯半球线对:**2,747** 场
- 样本(场×整数线):**3,135**;拟合失败 0
- 覆盖注记:**98.8%**(3,096/3,135)的可用整数线紧贴亚盘主线(overround 最小的半球线);
  离主线 ≥1 球的整数线全缓存只有 **39** 个样本——Pinnacle 半球线对基本只存在于主线附近

## 结果

### ① 总体:统计不可分,点估计网格略好

| 指标 | 亚盘直读 | 网格重构 | Δ(亚−网) |
|---|---|---|---|
| 3 路 log-loss | 1.06166 | **1.05973** | +0.00193 |
| 3 路 Brier | 0.64094 | **0.64019** | +0.00075 |

Δlog-loss 95% CI(按场自举):**[−0.00133, +0.00520] — 跨零,不显著**。
六月的价格空间冗余结论在结果空间成立:两法给的三路概率平均只差 1.4–1.9pp
(让胜 |ΔP| 均值 1.44pp / p90 2.89pp;让平 1.88pp / 4.11pp),对准头没有可测差别。

### ② 让平腿(免模型 vs 差值噪声):网格不输反赢

| | 亚盘直读 | 网格重构 | 实际频率 |
|---|---|---|---|
| 让平预测均值 | 23.17% | 24.24% | **26.57%** |
| 让平 2 路 Brier | 0.19402 | **0.19353** | — |

两法都低估让平,**网格更接近真实**。「亚盘免模型所以让平更准」被证伪:两条独立去 vig
累积的差值吃掉的噪声,大于 DC 模型误差。附带观察:网格让平仍比实际低 ~2.3pp,
与已知的「DC 轻微高估热门」同向,属已记录的校准特征,非新问题。

### ③ 热门区间:hint 不成立,95%+ 依旧没测

| fav 桶 | N | Δll(亚−网) |
|---|---|---|
| <0.60 | 2,245 | +0.0038(网格好) |
| 0.60–0.75 | 580 | −0.0024 |
| 0.75–0.85 | 210 | +0.0068(网格好) |
| 0.85–0.92 | 84 | −0.0204 |
| **≥0.92** | **16** | −0.0510 |

fav≥0.85 合并(N=100,77 场)配对自举:Δ = −0.02531,95% CI **[−0.06342, +0.01182] —
跨零,不显著**。≥0.92 只有 16 个样本,**该区间维持「未测」状态**——缓存里深热门场次太少,
这不是再跑一次能解决的,是数据本身稀缺。并且注意:深热门恰恰是竞彩整数线最容易**偏离**
亚盘主线的场景,而离主线的半球线对几乎不存在(全缓存 39 个)——亚盘直读在它唯一
可能占优的区间恰好**没有原料**。

### ④ 守卫问题(决定性):分歧不携带错误信号

按两法让胜 P 分歧幅度分桶,桶内比 log-loss——若大分歧桶里网格系统性更差,
「分歧→降级 EV 可靠性」的一致性守卫才有信息量:

| \|ΔP让胜\| | N | ll 亚盘 | ll 网格 | Δ |
|---|---|---|---|---|
| <1pp | 1,568 | 1.0703 | 1.0688 | +0.0014 |
| 1–2pp | 1,015 | 1.0581 | 1.0574 | +0.0007 |
| 2–5pp | 427 | 1.0627 | **1.0556** | +0.0071 |
| **>5pp** | 125 | 0.9789 | 0.9782 | **+0.0007** |

**>5pp 大分歧桶里两法照样打平**(2–5pp 桶里网格反而更好)。两法分歧大时,没有哪一方
系统性正确——分歧是共同噪声(陈旧报价、薄线宽 vig),不是网格出错的哨兵。
max 22.9pp 的离群分歧也不指控网格。**一致性守卫没有信息量,不建。**

## 裁决

1. **反推计算意义:没有。** 结果空间正面对决,亚盘直读对网格零增量(点估计还略负),
   让平腿网格更准,大分歧场景两法同噪。价格空间冗余(6 月)+ 结果空间打平(本测)双重钉死。
2. **竞彩 3 路让球引擎维持网格唯一路径**(`implied_handicap_lines`,WPO 1X2 + 真实 ou_line)。
   不加亚盘直读通道,不加一致性守卫。2 路亚盘展示板维持现状(实盘去vig 优先、网格兜底,
   那是展示口径,与本测无关)。
3. **就算想用也用不上**:亚盘直读要求相邻两条纯半球线同时被报价,该条件基本只在主线附近
   成立;竞彩整数线偏离主线的场次(深热门)恰好没有原料。网格是唯一始终有答案的方法。
4. 95%+ 深热门区间维持「未测」(N=16)。已知边界,不影响以上决策——那个区间亚盘直读
   同样没数据。

## 边界(诚实注记)

- 赔率是我们管道抓取的**赛前快照**(年龄不一,非保证收盘价);两法同读一个快照,
  对决公平,但绝对 log-loss 水平不代表收盘线水平。
- 联赛构成 = 我们缓存的联赛(欧主流+已训联赛为主),样本以均势场为主(fav<0.60 占 72%)。
- 四分之一线按设计排除(规避 ½+½ 评估陷阱),故本测不评「四分之一线直读」;
  该路径需要拆注结算,复杂度更高而上限不会高于本测的半球线直读。
- AET/PEN 场次按 score.fulltime 结算(缺分段才回退最终比分);带亚盘样本以联赛场为主,
  影响可忽略。

## 关闭

「Pinnacle 让分盘反推竞彩让球」问题**永久关闭**:价格空间(2026-06)、结果空间(本测)、
守卫信息量(本测 ④)三线全部测毕,结论一致。除非未来出现 95%+ 深热门大样本
(秋季也不会快——竞彩深热门本就少),不再重开。
