# 模型独立信号测试 (β test) — 结论存档

> 首次运行:2026-06-01 · 测试集:24/25 held-out walk-forward,GBM-eligible 4,331 场
> 复现:`nutmeg-beta-test`(或 `python -m nutmeg.v4.cli.beta_test`)

## 问题

我们的 CatBoost 模型,在 **Pinnacle 之外**,到底有没有、有多少**独立信号**?
(对应"模型评估"文章的第一优先级。)

## 方法

对 sharp(Pinnacle 去 vig)和模型做几何混合,扫描指数 β:

```
p_final_k ∝ p_pin_k^(1-β) · p_model_k^β        k ∈ {主, 平, 客}
```

在 held-out 集上找最小化 log-loss 的 β:
β≈0 → Pinnacle 已够;0<β<0.5 → 模型有少量独立信号;β>0.5 → 模型强;β≤0 → 模型无增量。

## 结果(1X2 临场盘)

**Sanity 通过**:模型单独 log-loss = 0.9960、Pinnacle 单独 = 0.9904,与历史基线分毫不差 → 数据可信。

| 变体 | 模型单独 | Pinnacle 单独 | 最优 β | 最优 log-loss | 任何 β>0 胜过 Pinnacle? |
|---|---|---|---|---|---|
| 原始 CatBoost | 0.9960 | 0.9904 | **−0.45** | 0.9898 | **否** |
| 温度校准 CatBoost | — | 0.9904 | **−0.15** | 0.9903 | **否** |

β 曲线(原始):β=+1.0→0.9960,+0.5→0.9924,+0.25→0.9912,**0→0.9904**,−0.45→0.9898。
**加入模型(β>0)单调地让结果变差。**

## 结论

**在 1X2 临场盘上,模型相对 Pinnacle 几乎无独立信号。**

- 正 β(加权模型)只会变差 → 没有正向增量。
- 最优 β 落在 0 附近、甚至微负(文章表里 β≤0 = "无增量 / 可能方向性偏差")。
- 那个 −0.45 的微弱改善(0.0006)**不可当真**:① 同一份数据既调 β 又评 β,是**样本内乐观估计**;② 一旦校准,最优 β 从 −0.45 缩到 −0.15、改善缩到 0.0001 → 那点好处**大半只是在修原始模型的过/欠自信**,不是真发现反向信号。

> 模型不是"错",而是在这个最难的市场上被 Pinnacle 完全盖住,是它一个(略噪)的影子。

## 重要 Caveat(避免过度解读)

1. **只测了 1X2 临场盘**——文章自己说这是最难的市场之一。不是对模型在所有场景(早盘 / 其他盘口)的判决。
2. **我们真正的对手是竞彩(soft book),不是 Pinnacle。** 相关问题是"我们的概率能不能赢竞彩的价",而 Pinnacle 去 vig 就是我们对此最好的估计——这正是系统现在用的(市场模式、今日推荐分歧跟市场)。

## 决策

- ❌ **不**盲目改服务层(给模型盘 1X2 加 Pinnacle 混合):干净的实现实质是把这些联赛的模型盘改成市场模式,β 过拟合风险高,真金白银收益未证且数据门控。
- ✅ **存档本结论**(本文件)。
- ✅ **做成可重复诊断**(`nutmeg-beta-test`):每赛季 / 每次重训后复跑,长期追踪"模型相对 Pinnacle 有没有发展出 edge"。将来 Layer B 真重训出 edge(β 转正),第一时间会看到。

## 这验证了什么

- "模型和 sharp 打架信 sharp" —— 对(模型在头牌无 edge)。
- 今日推荐三档把握度(分歧→观望) —— 对(分歧本来就是噪声)。
- 也解释了为什么 EV-vs-Pinnacle bug 是纯噪声:它卖的"模型 vs sharp 偏离",底层信号量约等于零。
