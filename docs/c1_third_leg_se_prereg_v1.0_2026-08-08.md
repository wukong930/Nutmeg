## 1. 被修的对象

`model/market_handicap.py:286-292` `c1_leg_lower_bounds` 的两条分支:

```python
if ln == -1:   # C1 碰了 让胜 + 让平;让负是锚,无 δ 误差
    return max(p_home - d, 0.0), max(p_draw - d, 0.0), float(p_away)   # ← 让负零收缩
if ln == 1:    # 镜像
    return float(p_home), max(p_draw - d, 0.0), max(p_away - d, 0.0)   # ← 让胜零收缩
```

`float(p_away)` / `float(p_home)` ⇒ 下界 == 点估 ⇒ 消费者 `_boardLegs` 的 `evLo ≡ ev`。

## 2. 问题陈述(为什么这是缺陷而不是设计)

「让负是锚,**无 δ 误差**」——这句话**对**。C1 重构确实没碰它。

缺陷在于消费者读错了这句话:`evLo` 是**排序键 + 5% 闸**,它需要的是「这条腿的
**不确定性**」,而不是「C1 有没有碰过它」。**「没被这次校准碰过」≠「没有不确定性」。**

这是同一病灶第三次发作,前两次都修了、都没盖到这里:

| 次 | 作用域 | 修法 |
|---|---|---|
| 1(prereg v1.8) | `\|line\|≥2` 未校准线 | 吃地板 `_UNCAL_SE=0.078` |
| 2(2026-08-08 v149) | 1X2 家族 | 实测 `ONEX_SE`,δ̂ 测不出但 SE≠0 ⇒ 下界照收 |
| **3(本文)** | **±1 线上未被 C1 触碰的第三腿** | 待定 |

`onex_calibration.py:48` 昨天写下的那句话字面上就在判本案:
> 保持 `lo=p` 等于断言 **SE=0**,那是**确定错的**。

## 4. 决策规则(**测量前钉死**)

### 4.1 点估:**一律不修**

无论 δ̂ 显著与否,**都不改 `_C1_DELTA` / `_C1_DELTA_P1`,也不给第三腿新增点估修正**。
本轮只动下界。理由同 δ₁ₓ₂:测不出偏差就不出偏差,编常数比缺常数更坏。

⚠️ 若第三腿的 δ̂ **显著**(|t| ≥ 2),那是一个**新发现**,不属于本预注册范围 ——
写进结果文档、另起一轮,**不在本轮顺手改点估**。

### 4.2 下界:上线条件

设第三腿的聚类 SE 为 `s`,上线值 `k·s`(k = `_C1_SE_K` = 2.0,不动)。

| 条件 | 动作 |
|---|---|
| `s` 与同线两个兄弟的 SE **同量级**(在 0.5×–2.0× 之间) | ✅ **上线** `s` |
| `s` 落在该区间外 | ⛔ **不上线**,写进文档,另议 |
| N < 1,500 或比赛日 < 400(任一线) | ⛔ 该线**不上线**,样本不足 |

**为什么用「同量级」而不是「显著」**:我们要的不是「这条腿有偏差」,而是
「这条腿的估计有多不准」。SE 本身就是答案,不需要过显著性闸。
区间是防止管线出岔子给出一个荒谬的 SE(如 0.5pp 或 10pp)。

⛔ **明确排除**:不借用 `_UNCAL_SE`(那是跨家族借地板,δ₁ₓ₂ 那轮已经否决过这个做法)。
第三腿是在**同一批样本、同一次重构**上直接测出来的,不需要借。

### 4.3 不作为上线依据的东西

- **ROI**。探索轮的配对 ΔROI 是 +0.55±2.44pp(t=0.45),**测不出**。
  与 δ₁ₓ₂ 部署时同形(−0.37±1.17)。**这是正确性修复,不许拿收益背书。**
- **argmax 翻转率**。探索轮报 30.9% 换腿 —— 那是**影响面**不是**正确性证据**,
  只写进结果文档供理解量级。

## 5. 范围与已知 caveat

- **覆盖**:football-data 的欧洲联赛。日职 / 杯赛 / 北欧 / 韩职 **0 覆盖** ——
  与 δ₁ₓ₂ 记录的是同一条 caveat,那些联赛的让球腿吃的是一个在别处测的 SE。
- **锚死于 2026-01-14**:秋季 Pinnacle 源若不恢复,本常数无法重测。
- **两条第三腿的 δ̂ 在探索轮都是负的**(腿被高估)。都不显著、都不修点估,
  但方向说明**零折扣是当前可选项里最不保守的那个**,两种误差同向叠加。
