# 收盘线漂移测量 — 「当下 Pinnacle 线」估「收盘线」到底差多少

**2026-07-02 · 原型测量(小 N,诚实呈现)** · 工具:`scripts/measure_close_drift.py`(随快照增厚可随时重跑)
**动机**:freeze-gap 下注 = 用**当下** Pinnacle 线当收盘线的替身给 EV 定价;隐含估计器是恒等映射(p̂_close = p_now)。它的误差 σ_P(τ) 直接决定提前 τ 小时下注时门槛要抬多少(σ_EV ≈ σ_P(τ)·SP),它的**系统性偏移**决定恒等映射是否有偏。

## 方法

- 数据:`odds_snapshots` 全部赛前 1X2 快照(WPO 去vig),7,524 行 / 136 场,轨迹中位跨度 ~6 天;`odds_update` 全覆盖且 p75 陈旧 = 0h(报价新鲜,无缓存污染)。
- **真收盘** = 距开赛 ≤75min 的最后一拍(主口径,N=27 场;敏感性 ≤180min,N=48)。
- 每场每 τ 桶取**最后一拍**做预测点,与真收盘配对;fav = 快照时 argmax 腿(每场每桶 1 观测,检验单位=场)。

## 发现

**① σ_P(τ) 曲线(本测量的主交付)** — 恒等映射误差从贴收盘的 ~1.2pp 单调爬到 4 天前的 ~3.3pp:
- 与既有结论交叉验证:0–3h 的 1.16pp ≈ 早前 71k 场测得的「收盘档 σ_P≈1–1.5pp」✓;
- **freeze-gap 常用时窗(τ≈3–24h)σ_P≈1.6–2.2pp = 收盘档的 ~1.4–1.8×**——提前下注的门槛必须按 τ 加宽,不能沿用收盘档常数;
- 换算成 σ_EV:τ=12h 押 SP=8 的冷门 → σ_EV ≈ 2.16pp×8 ≈ **17pp**——再次坐实「深冷门提前下注时平 5% 门槛≈零保护」。

**② fav 漂移:七个桶全部为正(+0.7~+1.5pp),但没过 2.8 的杆** — 热门的公允 P 走向收盘时系统性**上移**(冷门-热门偏差解锁的教科书方向)。t∈[1.4, 2.5],主+敏感性 13/13 个桶同号,**暗示性强、不可确认**(N=27,预注册纪律:t≥2.8 才算系统性成分)。若为真,推论很扎心:**提前下注时冷门的 EV 有系统性乐观偏差**(冷门 P 会向下漂 → 当下线高估其收盘公允;≈0.5pp 漂移 × SP 8 ≈ 4pp 假 EV)——这与 0/33 冷门假 +EV、⛔ 幻影退役完全同向。
**slope b ≈ 0**:常数漂移之外没有可测的按-P-比例结构。

## 结论 / 行动

1. **恒等映射保留**(无过杆的系统性成分可建模)——方向②的"漂移修正模型"**不建**,这是诚实结局;
2. **σ_P(τ) 曲线立即可用**:B2 方差门槛(`门槛=5%+z·σ_P·SP`)的 σ_P 应取 **σ_P(τ)** 而非常数——参数替换属 B2 范畴,仍按预注册 S5 过检后才进下注规则(本测量只提供曲线,不改规则);
3. **fav 漂移登记为待检假设**(挂靠预注册探索性;若秋季 N 增大后过 2.8,可升级为「提前下注冷门 EV 去偏移项」提案);
4. **重跑节奏**:closing cron(6-30 起)每天增厚真收盘;秋季受训联赛开赛后重跑一次出联赛别曲线(样本换血,今次的 WC+芬超构成不外推)。
