## §1 预检确证的事实(全部实测,2026-08-17)

### ① 逐联赛拟合**不可达** —— 这不是耐心问题

单联赛确立 δ₋₁ 需 `N > 4p(1−p)/δ²`,取 δ=0.046 / p=0.25 ⇒ **N ≈ 354**(±1 线)。
覆盖外各联赛当前(前向捕获,2026-06-11 起 66 天,±1 线):

| 联赛 | N | 按当前速率补齐 |
|---|---:|---|
| 芬超 | 58 | ~48 周(而芬超赛季 **10 月结束**) |
| 瑞超 | 50 | ~57 周 |
| 韩职 | 43 | ~68 周 |
| 挪超 | 42 | ~70 周 |
| 巴甲 | 24 | ~2.5 年 |
| 美职 | 17 | ~3.6 年 |
| 日职 | 9 | ~7.0 年 |
| 沙职 | 5 | ~12.7 年 |
| 荷乙 | 3 | ~21.2 年 |
| 日乙 | 3 | ~21.2 年 |

⇒ **N ∝ 1/δ² 决定了逐联赛这条路对市场模式人口是死的。** 唯一可行的是池化。

### ② 池化人口按 owner 口径**只算联赛**

owner 2026-08-17 定:「类似世界杯这种国家队杯赛就不去做校准了,我们的重心是联赛」。

| 层 | N | 明细 |
|---|---:|---|
| **联赛**(本预注册的人口) | **254** | 芬超58 瑞超50 韩职43 挪超42 巴甲24 美职17 日职9 沙职5 荷乙3 日乙3 |
| 俱乐部杯赛(**不入**本次) | 64 | 欧冠30 欧罗巴24 解放者杯5 英联赛杯4 欧超杯1 |

⇒ **254 / 需 354 = 差 100 行。** 名义速率 26.9 行/周 ⇒ ~4 周(2026-09-12)。
⚠️ **该 ETA 乐观**:北欧(芬超/瑞超/挪超)占 **150/254 = 59%**,赛季 10–11 月结束
⇒ 冬季速率会掉一半以上。真实到达时间见 §4 的复测规则,**不在这里猜**。

### ③ 🚨 前向捕获的价**不是收盘价** —— 和部署中的 δ 不是同一个被估量

`jingcai_sp.psc_*` 的采集时刻:**中位 1.6h 早于开球**(四分位 0.4h / 3.7h,N=490)。
而部署中的 `_C1_DELTA=0.046` 是对着 **football-data 的收盘价**拟合的。

⇒ 拿 T−1.6h 的覆盖外样本去比收盘基准的欧洲 δ,**league 和 timing 混在一起**,
分不出「芬超真的不一样」还是「1.6h 和收盘不一样」。
**这是本预注册最重要的约束**,§2.2 的设计整个是为了绕开它。

⭐ 反向含义(记下来,不在本次动):本仓铁律是「校准必须在**会下注的人口**上测」,
而竞彩封盘中位 3.0h ⇒ **T−1.6h 那批才更贴近我们真正下注的人口,收盘基准的 δ
本身才是妥协**。长期该重拟的不只是覆盖外,是全部。⛔ 那是另一份预注册。

## §2 检验设计(**在跑之前钉死**)

### §2.1 假设

**H₀:覆盖外国内联赛的 δ₋₁ 与欧洲 10 联赛的 δ₋₁ 相同(可池化)。**
备择:不同 ⇒ 范围闸继续按现状。

⛔ 本预注册**不**估计「每个覆盖外联赛自己的 δ」(§1① 已证不可达)。
⛔ 本预注册**不**包含 δ₊₁ / δ₋₂ —— 它们的量级更小、所需 N 更大,同一批样本判不了。

### §2.2 人口与两条臂(**同基准**是全部要点)

| | 定义 |
|---|---|
| **臂 A(覆盖外)** | `jingcai_sp`,`market='hhad'`,`abs(handicap_home)=1`,已结算,有 psc 1X2+O/U,`league` 归一后**不在**白名单,且属**国内联赛**层(排除国家队与俱乐部杯赛) |
| **臂 B(覆盖内)** | 同上,唯一差别:`league` 归一后**在**白名单 |

🚨 **两条臂必须来自同一张表、同一个采集管线** —— 这是绕开 §1③ 的唯一办法:
timing 基准在两侧同分布,差值里就只剩 league。
⛔ **绝不允许**臂 B 用 football-data 收盘样本(那正是混淆 timing 与 league 的做法)。

**实现约束(逐条,不许省)**
1. 分层前 `league` 两侧都过 `canonical_league`(见 §1④)。
2. 层归属用**显式清单**,不用 `is_domestic_club_league`(它的中文名表有洞)。
   清单写进脚本并在报告里逐字打印,**不许只打计数**。
3. δ 的估计量与 `cli/delta_calibration._n_delta` 同一口径:裸网格 P vs 实际命中,
   **逐腿**(让胜/让平/让负),不是三腿平均。
4. 只用 **c1=False 的裸网格**做基线 —— 拿被校准的数去校准是循环。

### §2.3 闸门:**跑之前必须同时满足**

| 闸 | 阈值 | 为什么 |
|---|---|---|
| G1 臂 A 的 N | **≥ 354** | δ=0.046 在 p=0.25 处的 δ=2SE 边界 |
| G2 臂 B 的 N | **≥ 354** | 差值检验两臂都要 —— 短臂决定功效 |
| G3 臂 A 的**比赛日簇数** | **≥ 30** | 同日多场共享定价冲击;`sigma_p_fit` v2.3 已证按簇自举会翻转判定 |
| G4 臂 B 的簇数 | **≥ 30** | 同上 |
| G5 臂 A 的**联赛数** | **≥ 5** 且**单一联赛占比 ≤ 40%** | 防止「池化」实际上是「测了芬超」 |

⛔ **任一闸不过 ⇒ 不跑,不报数,只记 ETA。** 「先看一眼」在本仓等于事后选判据。

**当前状态(2026-08-17):G1 254/354 ❌ · G2 53/354 ❌ · G5 待算。⇒ 现在不跑。**

### §2.4 判据(**先写死**)

统计量:`Δ = δ̂_A − δ̂_B`,逐腿。
标准误按**比赛日簇**自举(≥2,000 次重抽),不用独立同分布假设。

* **判定「可池化」** ⇔ 三条腿**全部**满足 `|Δ| < 0.010` **且** 95% 簇自举 CI 含 0。
  (0.010 沿用锚迁移预注册 §2.3 的等价界,**不新造阈值**。)
* **判定「不可池化」** ⇔ 任一腿 CI 不含 0 且 `|Δ| ≥ 0.010`。
* **其余一律「测不出」** —— 不是「可池化」。

### §2.5 三种结果分别怎么办(**现在写死,不许事后选**)

| 结果 | 动作 |
|---|---|
| **可池化** | 起草**第二份**预注册,提议把国内联赛层并入白名单。⛔ 本次结果**不直接改闸** —— 改闸是钱路变更,要单独的口令与回滚条件。 |
| **不可池化** | 范围闸维持现状,并把 Δ 的量级写进 `market_handicap` 注释 —— 闸做了实事,这是它的证据。 |
| **测不出** | 维持现状。记 ETA 复测,**不放宽闸**。⛔「测不出」≠「一样」—— 这是本仓栽过的原话。 |
