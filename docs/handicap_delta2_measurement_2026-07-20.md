# δ₂ 测量:±2 让球线的 DC 网格重构偏差 — 2026-07-20

**性质**:A′(prereg v1.7)同方法复刻到 |h|=2,防御性尺子测量,纯只读。若任何
常数进判闸,须先录预注册(v1.8)。脚本:scratchpad `delta2_measure.py`。

**一句话结论**:**深尾过估的病灶在 ±2 线同样存在且更危险**——−2 让胜(净胜 3+)
被裸网格高估 **+5~8pp**(双锚一致),而该腿平均 P≈39% 落在**甜区**,现有的冷门
门槛/A′ δ 带都罩不到它,+12~20% 的幻影 EV 可以直接过 +5% 闸。+2 线两锚同向
(深尾让负被高估)但 N≈40+42 太薄,量级钉不住——诚实结论 = 维持未校准。

## 1. 方法(= A′ 复刻)

- 人口:涓流史真实竞彩 ±2 线(每场最后一次变盘 = 终盘 SP),比分硬闸。
- 重构:生产代码原样(`devig_1x2` WPO → `implied_handicap_lines` 裸网格
  `c1=False`,有收盘 O/U 则一并拟合,fd 锚用 PC>2.5/PC<2.5,皇冠锚用其自带线)。
- δ_腿 = mean(网格覆盖P) − 赛果频率;SE = std(p−y)/√N(配对)。
- 双锚:A = football-data Pinnacle 收盘(欧洲+日本,2021-25);
  B = 皇冠收盘史(全联赛,2024-08+;⚠️ match_id 与涓流不同 id 空间,须用
  中文名+日期±1 join —— 已修入脚本)。

- 病灶结构与 ±1/家族完全一致:**网格把概率质量推进深尾**(让胜高估)、从肥侧
  抽走(让负低估);让平 ≈ 0。时代切片同向(2021-23 +3.5 / 2024+ +7.5,SE 内)。

- 让负被低估 −4.3pp → 它的真实 EV 比显示高 ~+9%(方向对用户有利,但同样是尺子歪)。
