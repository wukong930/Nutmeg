## 0. ⚠️ 授权范围的一处**收窄**,以及为什么

owner 说的是「±2」,但我们的测量对 **−2** 和 **+2** 给出的是**两个不同的结论**:

| 线 | 测量 | 「按测试结果修正」的含义 |
|---|---|---|
| **−2** | 让胜 **+6.4±2.5pp 高估**、让负 −4.3±2.7pp 低估;两锚同向,时代切片同向(2021-23 +3.5 / 2024+ +7.5,SE 内) | **部署常数** |
| **+2** | fd 让胜 **−14.80±7.82** vs 皇冠 **−2.93±7.77** —— 方向同、**量级差一倍**,N≈40、SE≈7pp | **不出常数**(测量文档 §5 原话:「+2:不部署数字」) |

**+2 的测试结果就是「测不出来」。** 给它编一个常数不是执行授权,是违背它 ——
这与「绝不瞎猜队名映射」是同一条红线:**错的常数比缺常数更坏**,因为缺的时候
护栏还会响,错的时候它静默地把幻影 EV 变成绿灯。

⇒ 本次部署 **只对 −2 出数字**;+2 与 ±3+ 走 §3 的「未校准地板」。

## 1. 部署内容(锁死,不得在评估前改)

### 1.1 δ₋₂ 常数(−2 线,即主队让 2 球)

| 腿 | 校正 | SE | 依据 |
|---|---:|---:|---|
| 让胜(净胜 3+ 深尾) | **−0.064** | 0.025 | 实测 +6.4pp 高估 |
| 让负 | **+0.043** | 0.027 | 实测 −4.3pp 低估 |
| 让平 | **+0.021** | 0.023 | **守恒强制**(见下) |

**守恒自检**:−0.064 + 0.043 + 0.021 = 0.000 ⇒ 三元组仍和为 1,可用于展示。

⚠️ 测量文档建议「让平不动」,因为它自身的估计 −2.1±2.3 跨零。但**三腿必须守恒**,
残差总得落在某处。把残差记到让平,得到 +0.021 —— 而这**恰好等于它自己的点估**。
两条独立理由指向同一个数,所以这不是硬凑;但**让平这条腿本身不显著**,它的下界
按自身 SE(0.023)照常拉宽。

### 1.2 判闸规则(与 A′ 完全同形)

- **显示** = 点估 + ± 区间(δ 带 ⊕ 冻结带,平方和)
- **判闸** = **逐腿下界** `点估 − 2·SE`(`c1_leg_lower_bounds`)
- 让胜下界带宽 ≈ 2×0.025 = 5pp,@SP 2.43 ≈ **±12% EV** —— 这正是 N=340 该有的
  诚实宽度。它的作用是**把幻影绿灯拦在闸外**,不是精修点估。

⚠️ **铁律(v1.7 得来)**:「绿灯 + 口头禁令」= 反模式。若只改显示不改判闸,
面板会一边亮绿一边写「别买」,用户只会看见绿。A′ 之所以自洽,就是因为闸和显示
出自同一次拟合。δ₋₂ 沿用这一点。

## 2. 预期效果(可证伪)

**P1**:−2 让胜腿的显示 EV 下降约 `0.064 × SP`。中位 SP 2.43 ⇒ **−15.6pp**。
P̄≈39% 落甜区、原幻影 EV +12~20% ⇒ **绝大多数该腿将不再过闸**。

**P2**:−2 让负腿显示 EV **上升** `0.043 × SP`。方向对用户有利,但下界(−2SE)
会吃掉大部分,过闸数量增加应**很少**。

**P3(真正的检验)**:秋季实盘,−2 腿的 **CLV** 应当**不再系统性为负**。
若累积 N≥100 条 −2 腿后,其 selected-CLV 仍显著低于 ±1 腿(cluster-robust t,
按比赛日聚类),说明 δ₋₂ 修错了方向或量级 —— **回来改模型,不改数据**。

### 2.1 ⚠️ P3 的人口:**只用国内俱乐部联赛计数**(owner 定,2026-07-27)

**判定 = `league_labels.is_domestic_club_league(league)`**(不是肉眼,不是事后挑):

| 类别 | 处理 | 例 |
|---|---|---|
| `domestic` | **计入** | 瑞超 / 挪超 / 英超 / SWE_ALLSVENSKAN / DNK_SUPERLIGA |
| `excluded` | 静默排除 | 世界杯·WC·欧洲杯·世预赛(国家队)、欧冠·欧罗巴·UCL·UEL(洲际杯) |
| `unknown` | **不计入,但必须在报告里点名** | 丹超(国内联赛,但中文缩写未收录) |

**为什么必须排除大赛**:δ₋₂ 是在**国内联赛**(football-data 各国 CSV + 皇冠)上
拟合的,大赛不在那个人口里。实证:2026-07 捕到的 15 场 −2 里 **10 场是世界杯**,
而小组赛的实力悬殊场次血洗率异常(5-0 / 5-0 / 4-0)。若把它们算进 P3,到秋天
N 凑够了、里面却混着一堆世界杯 —— 又是一次「人口不对」,与
`[[statistics-on-the-bettable-population]]` 同一个错误的第三种穿法。

**为什么 `unknown` 要单列**:悄悄少算 N 和悄悄混入错人口一样坏。丹超是活例 ——
它是国内联赛、竞彩也上架,但 `_EN_TO_CN` 没收录中文缩写,cron 写的中文行会掉出
计数。⚠️ 补中文缩写**必须等竞彩上架后照抄官方写法,绝不照英文猜译**。

**⚠️ 实现红线**:中文标签**绝不能**裸用 `competitions.competition_type_of` ——
它只认 EN code,中文进去会对**所有东西**返回 `"league"`,世界杯/欧冠会被静默算成
联赛(实测,我写这条时差点踩)。双轨判定的理由写在 `classify_league` 的 docstring。

## 3. 未校准线的**护栏地板**(+2 / ±3 / 更深)

这是本次一起修的、比 δ₋₂ 更隐蔽的缺陷。原实现:

```python
se = _C1_DELTA_SE if line == -1 else (_C1_DELTA_P1_SE if line == 1 else 0.0)
if se == 0.0:
    return p_home, p_draw, p_away      # 下界 == 点估
```

`se = 0` 不只是「不修正」,它**同时松了两道**:

1. **± 带反而变窄** —— 前端 `half = hypot(dHalf, frzHalf)`,`dHalf = (evHi−evLo)/2`。
   下界等于点估 ⇒ `dHalf = 0` ⇒ 带只剩冻结带。**面板在它最不了解的线上显示最窄的
   不确定区间** —— 「没测过校准」被渲染成了「没有不确定性」。
2. **判闸门槛反而更低** —— `pass = evLo >= minEv`,而 `evLo == ev` ⇒ 直接拿点估
   过闸,而 ±1 腿要拿 δ−2SE 的下界过。**越不可信的线越容易变绿**,符号反了。

**修法**:未校准线不出点估校正(继续不猜),但**下界按一个地板 SE 拉宽**:

```
_UNCAL_SE = 0.078      # +2 两锚实测 SE 的较大者(fd 让胜 ±7.82)
```

对 |line| ≥ 2 且非 −2 的所有线,三腿一律 `点估 − 2×0.078`。

**这会让绝大多数 +2/±3 腿过不了闸 —— 那是正确结果**,不是副作用:
我们无法排除 +2 上存在 15pp 的高估,而 15pp @SP2.4 ≈ 36pp 的幻影 EV。
在排除不了之前不下注,是这个项目的默认动作。

⚠️ 地板值 **0.078 是实测量级不是猜测**,但它是**借来的**(来自 +2 的测量,
用在 ±3+ 上)。±3+ 从未测过,家族病灶随深度只会更大不会更小,所以借用是保守方向。
**这一点必须在秋季 P1 回填后重测**,不许当成永久常数。

## 4. 不做什么

- **不改平 5% 闸本身** —— 这次改的是喂给闸的 P,不是闸。
