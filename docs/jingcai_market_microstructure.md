# 竞彩市场本身:结构如我们所料,但文献是空的 —— 我们只能靠自己测

**状态:📚 参考文献 + 战略裁决** · 记于 2026-06-24 · 回答「我们真正下注的那个市场,到底什么结构、有没有外部证据」

> **出处说明**:多 agent 深度研究(中文源:体彩中心 / sporttery.cn / lottery.gov.cn / 财政部 / 网信办 + 500.com IR + 财经媒体),搜索 + 抓取 + **对抗式核查全程完成**(20 条 3-0 confirmed)。凡标 **[3-0]** 为全票通过的官方/一手引文。

> **一句话裁决**:**竞彩的结构完全坐实了软水前提**(行政设定的固定赔率,且**在售卖窗口内按国内销售流实时调线** —— 所以它带中国散户偏差,不是纯追 Pinnacle)。**但致命的是:关于竞彩效率/偏差/返奖率/vs-Pinnacle 缺口,外部文献是空的** —— 学术、行业、官方都没有可引证据。**软水论的核心实证支柱没有任何外部背书,完全靠我们自己的测量。** → **没有外援。我们的前向 CLV 测量是这个论点唯一会存在的证据。**

## 1. 结构:行政设定的固定赔率,且按国内销售流调线 [3-0,官方]
- **固定赔率、非彩池(pari-mutuel)。** 体彩中心按每个组合设**固定奖金**,无奖池累积、无派奖,与彩池型足彩明确区分。
- **锁在「你那张票」**:`投注时赔率以投注时的赔率为准,不因投注的增减而改变`(sporttery.cn 一手)。
- **关键限定(已核实):固定 = 锁在你的票面,不是锁在时间** —— `在销售过程中,该固定奖金会根据销售等情况进行实时的调整`。即**售卖窗口内,体彩按国内销售情况(销售情况/handle)实时调线**,不是纯盯亚盘/sharp。
- → **竞彩的移动 = 一部分追 sharp + 一部分追国内散户流。** 软水(若有)就藏在**散户流推动的偏离**里,不只是「滞后的 Pinnacle 影子」。这比我们原来的「滞后劣化影子」框架更准。

## 2. 2015 网售禁令:durable 的行政约束(不是市场事件)[3-0,一手/监管]
- 分阶段自上而下:2015-01-15 三部委自查自纠通知 → 02-25 省中心停 → 02-28 全国 → **04-03 八部委 18 号公告**(财政部/公安部/工商总局/工信部/民政部/央行/体育总局/银监会)固化,覆盖福彩 + 体彩(含竞彩)。
- **法律钩子**:无财政部批准不得网售;`财政部尚未批准任何彩票机构正式开通利用互联网销售彩票业务` —— **至今零批准**,故**至今零售终端为主**。
- **拿掉的流动性**:2014 网售 ~**850 亿(占 22.2%)**;2014 世界杯 ~**70% 走线上/移动**(重度竞彩)。禁后只能线上下单、本地实体店出纸票。
- → **竞彩定价是行政约束下的产物,不是自由市场** —— 软水前提的结构基础坐实。

## 3. 致命的空白:返奖率与效率,外部无可引证据 ⚠️
- **[0-3,refuted] 竞彩足球 1X2 的返奖率 / overround 拿不到。** 每个候选数字(68-69%、73%、86.3%、9.18% 算例)都被对抗核查**否决**(来源是博客/新闻级,官方页不干净披露)。→ **我们实测的 ~12.9% vig 是我们自己的数,没有外部佐证。**
- **[medium,absence] 竞彩效率/偏差零文献。** favorite-longshot / 主场 / 平局 / 散户超买(大球队/大球/热门)—— **没有任何同行评议或数据支撑的研究**;**竞彩 vs Pinnacle/亚盘缺口也无人发表**。核查的 20 条 confirmed 里 19 条是 2015 禁令、1 条是固定赔率机制,**效率/偏差/缺口一条都没survive。**

## 4. 对 Nutmeg 的战略裁决

1. **软水论无法外包给文献 —— 文献不存在。** 没人发表过竞彩软不软、偏差在哪、怎么 gap Pinnacle。**我们是这个问题唯一的研究者。**
2. **这抬高了我们自己测量基建的全部价值。** `jingcai_sp` + `clv_ledger` + 冻结缺口测试 + 比分/总进球捕获 —— **这是软水论唯一会有的证据来源**,不是「攒着等外部验证」,而是「我们就是验证本身」。值得继续投。
3. **软水机制要更新**:不是「纯滞后 Pinnacle」,而是**「行政设定 + 按国内销售流调线」** → **偏差应集中在中国散户钱堆的地方**(大球队、热门、大球 —— 经典散户偏差,但**竞彩上无人量化过**)。秋天测软水时,**按「散户重仓 vs 冷门」切**,可能比单纯按联赛切更能找到偏差。
4. **vig 是官方不透明的** —— 体彩不干净披露足球固定赔率返奖率;**我们实测的 ~12.9%(1X2)/ 让球类似 是我们最好的数**,继续用,但知道它是自测、非官方。
5. **与 DNA 一致**:measure-first 不再是「保守姿态」,而是**「除了自己测,没有别的路」** —— 文献空白把这条纪律从选择变成了必然。

> **净结论**:竞彩结构 = 行政固定赔率 + 国内流调线 + 零售约束,软水前提坐实;但**外部对竞彩效率/偏差/vig 一无所知** —— 软水论完全是我们自己的实证项目。**继续测、按散户偏差切、把 ~12.9% 当自测基准。** 这把「我们为什么要自建数据库 + CLV 账本」从「锦上添花」升级成「唯一证据通道」。
