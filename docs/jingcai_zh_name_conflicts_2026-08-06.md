## 怎么看这张表

* **竞彩票数** = 这个中文名在 vote feed 里出现几次(权威度,不是重要度)
* **近 90 天盘面** = 这支队在 `odds_snapshots`+`jingcai_sp` 里出现几次(**你会不会看到它**)
* 盘面 0 的那些现在改不改都看不见,秋季才显形

## 采纳方法

`--apply` 整块重写)。改完跑 `.venv/bin/python -m pytest tests/v4/test_team_name_zh.py`。
