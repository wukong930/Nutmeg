# 竞彩 线源残差分解 — 软是因为陈旧,还是因为本土偏差?

_2026-07-06 · 探索方向 #2 · 只读测量,赛前可测,零 API · 工具 `nutmeg-line-origin`_

## 问题

竞彩的 SP 坐落在 sharp 真值(Pinnacle 收盘去vig)旁边,常有缺口。这缺口有**两种
完全不同的成因**,它们指向**不同的边**:

- **陈旧(freeze-gap,S1 领域):** 竞彩锚在一个**旧的** Pinnacle 上,而 sharp 线之后
  动了。这可以用一条更新鲜的线 / 临场信息去打。
- **本土残差(retail-bias,S2 领域,价格侧):** 竞彩从**一开始**就被设在偏离 sharp
  的位置 —— 国内钱、主队偏好、本地信息。这是一条**常驻**的、与陈旧正交的偏差。

分开这两者,是「把解读盘口做深」的核心一步。之前所有软水测量都只看竞彩 vs Pinnacle
**收盘**的一个静态缺口,从没区分过这缺口是「陈旧可解释」还是「本土不可约」。

## 方法(以及为什么幼稚版不够诚实)

天真做法:`本土 = 竞彩 − Pinnacle开盘`,`陈旧 = 开盘 − 收盘`,加起来正好等于总缺口
`竞彩 − 收盘`。**但这有致命漏洞**:一条**完美镜像 sharp 收盘**的竞彩线,本土偏差其实
为零,天真版却会因为「竞彩 ≠ 开盘」给它记一大笔假本土残差。

**诚实修正(band 法):** 陈旧应当被赋予 sharp 线**实际走过的全部范围**的信用。对每条
腿,取所有快照 WPO 去vig 公允 P 的 **band = [min, max]**。若竞彩去vig P 落在 band
**之内** → 存在某个陈旧锚能产生它 → 陈旧足以解释,不需动用本土。只有竞彩落在 band
**之外**的那部分,才是**不可约本土残差** —— 任何陈旧锚都解释不了:

```
irreducible_i = 竞彩_i − clamp(竞彩_i, lo_i, hi_i)   (落区间内 = 0)
```

这是本土偏差的**保守下限**(把一切疑点都判给陈旧)。口径:P=WPO 去vig;语料=同时有
Pinnacle **多快照线史**(≥2 次捕获)与竞彩 SP 的比赛,经 `national_match_key` 跨源配对。

## 结果(N=116 场;发现期夏季样本)

**先验证线史够不够宽**(否则陈旧被低估、本土被高估):116 场的 Pinnacle 线史窗
**中位 127 小时(5.3 天)**,137/163 场 ≥24h,117/163 场 ≥72h。**线史很宽,陈旧被充分
观测** —— 结论不吃「窗太窄」的亏。

**① 平均量级(逐腿绝对值):**

| 分量 | 均值 |
|---|---|
| 陈旧度 \|开−收\|(sharp 自身位移) | 2.3pp |
| 总缺口 \|竞−收\|(竞彩距 sharp 真值) | 2.9pp |
| **★不可约本土 \|竞在区间外\|(诚实下限)** | **1.7pp** |

**② 本土偏差为主 —— 且扛住了对抗性修正。**

- **76% 的腿「陈旧解释不了」**(竞彩落在 Pinnacle 整个已观测区间之外)。
- 不可约本土 = 总缺口的 **59%**。
- 对照:天真版(竞彩−开盘)给 63%。诚实 band 版只把它削到 **59%** —— 即便**把一切
  疑点都判给陈旧**,本土仍占主导。**这个发现是稳健的,不是「竞彩其实在追收盘」的假象。**

**③ 逐路不可约本土残差(带符号,正=竞彩隐含概率在 sharp 区间之上):**
主 +1.0pp / 平 −0.7pp / 客 −0.2pp。竞彩系统性地把主队隐含概率推高、平/客推低。

**④ 诚实剃刀 —— 不可约本土残差随散户票走(排除陈旧后仍在):**

| 档 | 均票 | 不可约本土 |
|---|---|---|
| 低票 | 15% | **−1.4pp** |
| 中票 | 30% | −0.6pp |
| 高票 | 55% | **+2.0pp** |

单调、跨零。竞彩把**人群涌入**的腿的隐含概率推到 sharp 区间**之上**(+2.0pp,价更短、更
贵),把**人群回避**的腿推到区间**之下**(−1.4pp,价更长)。而且这是**陈旧解释不了**的
那部分 —— sharp 线在整个观测期里都没走到那里。

## 裁决

1. **竞彩软水以「本土偏差」为主,不是单纯陈旧。** 59% 的缺口不可约(即便对抗性地全额
   信用陈旧),76% 的腿落在 sharp 全区间之外。**首次把软水成因拆开量化。**
2. **本土偏差跟着散户票走**(④ 单调跨零),且是**陈旧无法解释**的部分 —— 这是 S2
   散户逆向论题在**价格空间**的独立佐证,与冻结缺口正交。
3. **方向 = 反人群:** 低票腿竞彩隐含概率被压到 sharp 之下(−1.4pp,价更长=对下注者更
   友好),高票腿被推到 sharp 之上(+2.0pp,价更短)。软腿在**低票侧**,与探索 #1(逐路
   vig:低/中票非热门腿水最薄 ~8%)**指向同一角落**。
4. **仍不凭空造 +EV。** 本土残差 ±1-2pp 远小于 ~13% 的 overround 墙;它**定位**软水在
   哪条腿(低票 + 反人群方向),不单独翻正。要翻正仍需叠加(vig 最薄区 + 冻结缺口 + 本土
   反人群三者同向)。

## 与探索 #1 的关系(三角互证)

| | 探索 #1 逐路 vig | 探索 #2 线源残差 |
|---|---|---|
| 测什么 | 竞彩怎么**铺 overround**(含 vig 的逐腿 −EV) | 去 vig 后竞彩往哪**偏**(相对 sharp) |
| 软腿定位 | 低/中票**非热门**腿 vig 最薄(~8%) | 低票腿隐含概率被压到 sharp **之下** |
| 新增 | —— | 排除了**陈旧**这个混淆,证明偏袒是**本土**的 |

两条独立测量指向**同一个角落**:低散户票、非热门、反人群的腿,是竞彩最软的地方 ——
既收最薄的 vig,又在去vig 后往对下注者友好的方向偏。**#2 的增量**是证明这偏袒**不是
陈旧**(Pinnacle 在整个观测期都没走到那,76% 的腿如此),而是竞彩自己的本土定价选择。

## 边界

- N=116,发现期夏季(世界杯 + 友谊 + 零星联赛),**非受训面秋季总体**;描述性均值,未做
  聚类 t / 显著性检验。
- band 用**已观测**快照的 min/max;若某段 Pinnacle 移动没被我们的快照抓到,band 偏窄
  → 本土被略微高估。但线史中位 5.3 天已相当密,残余偏差有限。
- P=WPO 去vig(捕获期,非保证收盘绝对水平);测的是竞彩相对 sharp 区间的**位置**,对
  绝对水平不敏感。
- **探索性,不动钱。** 「本土反人群偏袒集中在低票腿」是假设,秋季须进预注册(仿 S2/S6)
  + 过 CLV 闸门才可能影响下注。工具随 vote/SP + odds_snapshots 每天累积,秋季线史攒厚
  即可复跑读数。
