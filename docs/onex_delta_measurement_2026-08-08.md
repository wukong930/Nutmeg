## 一句话

**测不出偏差** —— Pinnacle WPO 去vig 的 1X2 P 在竞彩欧洲人口上校准良好(三条腿
|t| 全 < 1)。**但这不是「无事发生」**:SE 不为零,所以下界仍然要收 ——
**`lo = p − 1.16pp`**(prereg §1 预先写明的那个结局)。

## 2. 主分析

```
主胜   δ̂ −0.37pp ± 0.58   t = −0.64
平局   δ̂ −0.10pp ± 0.55   t = −0.18
客胜   δ̂ +0.47pp ± 0.56   t = +0.85
守恒   Σδ̂ = −0.0000pp ✓(结构性恒等,非拟合结果)
```

SE 按**竞彩比赛日聚类**。聚类 SE / 朴素 SE = 1.03–1.04 —— 聚类在这里很弱,
合理:同一天的场次分散在不同联赛,共同冲击有限。

## 3. 预注册的四项次分析(全部通过 ⇒ 常数形式存活)

| | 结果 | 判定 |
|---|---|---|
| ① 残余 favourite-longshot | d 对 P 回归 β = **+0.0336 ± 0.0232, t = +1.45**;跨 P 全域端到端 +2.82pp | ✅ 不显著,常数形式存活。**但方向一致且不小 —— 秋季数据变多后第一个该复查的就是它** |
| ② 半分稳定性 | 三条腿**符号全翻**(平局 −1.58 → +0.96) | ✅ 支持 null:真偏差不会翻号,噪声会 |
| ③ 逐联赛异质性 | Cochran's Q:主胜 p≈0.32 (I²=14%) · 平局 p≈0.66 (I²=0) · 客胜 p≈0.90 (I²=0) | ✅ 拒绝不了同质 |
| ④ 可单关子集 | N=969,三条腿 \|t\| ≤ 0.81 | ✅ 同向,但 N 小 SE 翻 3 倍 |

⚠️ ③ 的功效有限(9 个联赛、每格 SE 1.2–3.0pp),「拒绝不了同质」≈「没能力分辨」,
**不是「证明了同质」** —— 和 δ 同源性检验只有 26% 功效那次是同一句话。

## 5.1 建议部署(原文,保留)

按 prereg §6:δ̂ 不显著 ⇒ **点估不动**,只收下界。

```python
# 1X2 腿的下界 SE —— 实测,非猜测(N=6,516 / 871 个比赛日,比赛日聚类)
ONEX_SE = (0.0058, 0.0056, 0.0056)    # 主胜 / 平局 / 客胜
# lo_o = p_o − ONEX_SE_K * ONEX_SE[o]  ⇒ ≈ p − 1.16pp
```

⭐ **不把 δ̂ 带进下界**,尽管 prereg §6 字面允许。理由:客胜 δ̂=+0.47 会把下界从
−1.11 **松到** −0.64 —— 让一个和噪声无法区分的正数去放松判闸,正是赢家诅咒的形状。
与本项目「+2 线不出点估、只拉宽下界」同一立场。(这是对预注册的**收紧**,不是放松,
按 §6 精神合规;若 owner 认为该严格照字面执行,两组数都在上面。)

## 6. 这把不对称收窄了多少

`evLo` 里各类腿的收缩量 = `k·SE`(k=2):

| 腿 | 收缩量 | 出处 |
|---|---|---|
| 让球 −1 线 | 1.56pp | `_C1_DELTA_SE` 0.0078 |
| 让球 +1 线 | 2.02pp | `_C1_DELTA_P1_SE` 0.0101 |
| 让球 −2 线 | 4.6–5.4pp | `_C2_SE_*` |
| 未校准线(+2 / ±3+) | 15.6pp | `_UNCAL_SE` 0.078 |
| **1X2(今天)** | **0** | `lo=null` |
| **1X2(建议)** | **1.16pp** | 本测量 |

⇒ 与 ±1 线的差距从 **1.56/2.02pp 收到 0.40/0.86pp**。与更深的线仍有差距 ——
**那是对的**,那些线本来就更不确定。

⚠️ **更正**:我 2026-08-08 早先口头把这个不对称说成「5~15pp EV」,那是拿
δ 的**点估**(0.046)乘 SP 算的。错了 —— 点估修正对展示 P 和下界**同时**生效,
不产生排序上的不对称;产生不对称的只有 `k·SE`。正确量级见上表(±1 线 1.56–2.02pp,
乘 SP≈3 是 ~4.7–6.1pp EV;深线才到十几 pp)。

## 9. 为什么同时上「让球腿占比」

部署后回测显示池子会从 **41% 让球腿倒向 78%**(1X2 占比 59.3%→21.9%)。让球腿的 P 是
从 Pinnacle 1X2+大小球**反推**的,1X2 腿的 P 是 Pinnacle 直接给的。判闸下界已经在给
反推的额外不确定性定价 —— 但**「一票四条腿全是让球腿」是另一回事**:它们共用同一套
重构机器,错误相关(和 C₁ 集中度帽同一个关切)。

⚠️ 多少算多**没人测过** ⇒ 面板上这个数**没有阈值、没有颜色、不进任何选择路径**
(`test_handicap_share_is_display_only` 钉住)。它是个仪表,不是个闸。
要判闸须自己的预注册 —— 「绿灯 + 口头禁令」是已知反模式,这里用的是「只显示不判闸」。

## 10. argmax 翻转实测(scripts/onex_argmax_flip.py)

| | |
|---|---|
| 换了当选腿的比赛 | **2,511 / 6,516 = 38.5%** |
| 当选腿是 1X2 的比例 | 59.3% → 21.9% |
| 为什么翻这么多 | 两类腿 evLo 差**中位 +0.62pp**、四分位 [−1.00, +2.81]、67.2% 落在 ±2.9pp 内 —— 秤本来就几乎是平的 |

**配对**检验(同一批比赛,⛔不许拿两条独立 ROI 相减):

```
单腿 argmax   ΔROI = −0.37pp  ±SE 1.17   t = −0.31   (6,516 场 / 871 个比赛日)
2 串          ΔROI = +3.29pp  ±SE 9.77   t = +0.34
3 串          ΔROI = +4.88pp  ±SE 19.59  t = +0.25
```

单腿那个界很紧(95% 约 [−2.7, +2.0]pp)⇒ **不是「样本不够看不出」,是真的没有效果。**

⭐ **结论:这是正确性修复,不是盈利修复。** 部署理由是「一个我们知道不对的估计不该
因为『改了也不赚』就留着」,**不是**「能多赚」。数据明确说了赚不到。
与项目自己测过的「EV 是排除器不是排序器」「名次不预测 ROI」一致:两条几乎打平的腿
之间选哪条,本来就不携带信息。
