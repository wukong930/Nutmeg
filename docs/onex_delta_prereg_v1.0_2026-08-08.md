# 1X2 腿下界修正 δ₁ₓ₂ —— 预注册 v1.0(2026-08-08)

> **状态:草稿,待 owner 口令。** 本文在**看到任何偏差数字之前**写就并提交。
> 测量脚本 `scripts/onex_delta_calibration.py` 在本文提交后才允许跑。

## 0. 起因

`_boardLegs`(dashboard.html)对两类腿算 `evLo` 的方式不对称:

```
让球腿:  evLo = lo × SP − 1     lo = 点估 − k·SE(δ)   ← 真的收缩
1X2 腿:  evLo = p  × SP − 1     lo 传 null ⇒ evLo ≡ ev  ← 没收缩
```

串关池每场取 `evLo` 最高的一条腿,两类腿在**同一个排序里竞争** ⇒ 让球腿是缩过水的、
1X2 腿不是 ⇒ **1X2 腿在 argmax 里被系统性偏袒**,量级 ≈ δ·SP,按 δ₋₁=0.046、SP 2~3
算是 5~15pp EV。

⚠️ **先更正一个误判(2026-08-08,本文作者)**:我一开始把这条描述成
「1X2 腿拿了『没测过 ⇒ 当成零』的待遇」,和 +2 线 `se=0` 那个已修的 bug 同族。
**不对。** `c1_leg_lower_bounds` 的 docstring 写得很清楚:它返回的是
「每条腿在 **δ 估计误差**下的自身下界」—— 保护对象是**让球重构这一步引入的误差**。
1X2 腿没有重构这一步(P 是 Pinnacle 去vig 直接得到的),所以在**该框架的口径内**
`lo = p` 是自洽的,不是漏洞。0 线也同样返回点估,注释写「0 线:无让球偏差可言」。

⇒ 真正待答的问题因此变了,变成:**Pinnacle WPO 去vig 的 1X2 P,在竞彩会下注的
人口上,本身有没有可测的校准偏差?**

## 1. 为什么这个测量**不可能空手而归**

即使测出偏差 δ̂ = 0,下界仍然要收缩 —— 因为 **SE 不为零**。

```
lo = p + δ̂ − k·SE(δ̂)        k = 2(沿用 _C1_SE_K)
δ̂ = 0 时:  lo = p − 2·SE
```

这是本项目已经采纳过的立场,不是新发明:`_UNCAL_SE = 0.078` 那段注释写着
「**没测过校准 ≠ 没有不确定性**……不猜点估,但下界按地板 SE 拉宽」,理由是
`se=0` 的老写法让「越不可信的线越容易变绿」。1X2 腿今天正是 `se=0`。

⇒ 本测量的产出**下限**是一个纯 SE 驱动的下界;上限是 SE + 一个实测偏差常数。
两种结局都会让上面那条不对称收窄,**都不会是「无事发生」**。

## 2. 估计量

对每个结果 o ∈ {主胜, 平, 客胜},在人口 S 上:

```
δ_o = (1/N) Σ_i [ 1{result_i = o} − P_o(i) ]
```

- **P_o = Pinnacle 收盘 1X2 经 WPO 去vig**(`nutmeg.v4.model.devig.devig_1x2`)。
  ⚠️ 必须是 WPO,不是 basic。服务路径(`_pinnacle_devig_1x2`,routes.py:1979)用 WPO;
  已有的 `scripts/parlay_backtest.py` 用的是 `_devig3`(basic)—— **口径不同,不许直接复用**。
- 守恒自动成立:Σ_o 1{·} = 1 且 Σ_o P_o = 1 ⇒ δ_主 + δ_平 + δ_客 ≡ 0。
  ⇒ 三条腿的修正天然是合法概率三元组,不需要像 δ₋₂ 那样手工配残差。
- **正号 = P 低估**(实际发生得比 P 说的多)⇒ 修正为 P + δ。

## 3. 人口 S(**本文最承重的一节**)

红线:「统计量必须在会下注的人口上算」「校准必须在真实竞彩线上测」。

**S = 竞彩历史上真实上架过 had 盘、且已结算的比赛** ∩ **football-data 有 PSC 收盘价**。

## 4. 统计口径

- **聚类**:按竞彩比赛日(`close_date`)聚类 SE。同日多场共享联赛/天气/轮次冲击,
  朴素二项 SE 会低估。(δ 那次的教训:朴素 SE 是**下限**。)
- **k = 2.0**(≈95% 单侧),与 `_C1_SE_K` 一致,不另立。
- **主分析**:全 S 上的三个 δ_o + 聚类 SE。
- **预注册的次分析**(先写下来,免得事后挑):
  1. **按 P 分箱**(P 的十分位):WPO 已经在修 favourite-longshot,残余是否随 P 变化。
     若显著随 P 变,则 δ 不该是常数 —— 那会推翻常数形式,须另立预注册。
  2. **半分稳定性**:按日期中位切两半,两半 δ̂ 同号且量级相近才算稳。
  3. **逐联赛异质性**:τ² 是否 ≠ 0。若显著异质,常数形式同样受质疑。
  4. **可投注性敏感性**:限制到 `single_available=1`(可单关)子集重跑。
- **多重比较**:上述 4 项次分析 + 3 个 δ_o = 7 个检验,次分析一律按 BH-FDR
  控制在 0.10,且**次分析不单独构成部署依据**。

## 5. 已知的、不打算假装解决的偏倚

1. **收盘 ≠ 我们下注时看到的线**。PSC 是收盘价,我们的 P 更旧。⇒ 本测量给的是
   一个**比我们实际拥有的估计更准**的东西的校准。δ̂ 因此可能偏小、SE 偏窄。
   陈旧度**不在**本测量里 —— 它已由 freeze-gap 的 `_frzHalfEv` 单独定价
   (且按设计不进判闸)。两项不许合并、不许互相顶替。
2. **football-data 的 Pinnacle 已死于 2026-01-14** ⇒ S 的尾巴止于该日,
   2026 年 1 月之后的竞彩场次全部不在 S 内。⇒ 有时代漂移的话本测量看不见。
3. **别名表的洞**(德乙/日职)让 S 的联赛构成偏向头部联赛。逐联赛异质性检验
   (§4.3)是对这条的部分兜底,不是解决。

## 6. 决策规则(**部署前须 owner 口令,本文只写规则**)

对 o ∈ {主胜, 平, 客胜},在 §3 的欧洲范围内:

- **一律部署下界** `lo_o = P_o + δ̂_o − 2·SE(δ̂_o)`。
  即使 δ̂_o 跨零也部署 —— 这正是 §1 的全部理由。
- **点估修正 δ̂_o 只在 |δ̂_o| ≥ 2·SE 时进展示**;否则展示保持 P_o 不动,
  只有下界收缩。(与 +2 线「不出点估、只拉宽下界」同一处理。)
- **范围外的 1X2 腿**(日职/杯赛/北欧/韩职/美职/2026-01-14 之后):
  不猜点估,下界吃**地板 SE**。地板取本次实测 SE 与 `_UNCAL_SE=0.078` 中的**较大者**
  —— 借用属保守方向,且必须在代码注释里写明「借来的,秋季须重测」。
- **若 §4.1 测出 δ 显著随 P 变化,或 §4.3 测出联赛间显著异质** ⇒ 常数形式作废,
  本预注册**不部署任何东西**,改立分层版预注册。
