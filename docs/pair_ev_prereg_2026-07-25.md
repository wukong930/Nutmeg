# 配对 EV — Phase 1 预注册(2026-07-25)

**状态**:测量期。**不改任何判闸,不产生下注建议。**
Phase 2(把配对接进真判闸)只有在本文档的主结局为正、且 N 足够时才讨论,并须另走
预注册 v1.8 + 先回测。

---

## 0. 为什么要测

竞彩**只有 17% 的场次开单关**(2026-07-25 实测,标签合一后:韩职 29% / 瑞超 21% /
挪超 13%;欧罗巴·芬超·欧冠·巴甲·美职 **0/59 全零**)。其余 83% 必须串关 ——
**逐腿判闸判的是一个你买不到的对象**。

串关 EV 是乘的:

```
EV_串 = P₁P₂·SP₁SP₂ − 1 = (1+EV₁)(1+EV₂) − 1 = EV₁ + EV₂ + EV₁·EV₂
```

两条 +3% 的腿 → **+6.09%**,过 5% 闸,而两条腿单独都不过。现在的逐腿闸看不见它。

**理论上的好处**:EV 近似线性加,σ 平方和加 ⇒ 信噪比变好。
每腿 EV=3%/σ=4%:单腿 EV/σ=0.75,二串 6.09%/5.66%=**1.08**。

**⚠️ 但这个好处有前提**:两腿的 EV 误差**独立**。若一起错(去vig 口径系统性偏、
Pinnacle 同时在动、同联赛同日共同因素),σ 就是线性加,好处归零。
**这个前提本身就是要测的东西之一**(§4 次要结局)。

**⚠️ 风险确实存在,但不是我最初写的那个**(2026-07-25 当天蒙特卡洛更正,见 §7)。
真实机制:配对选中的是**两个**顺序统计量而不是一个,两条腿各自带着「因为被选中所以
噪声偏高」的偏差,串起来相加 —— 实测**虚高约 2 倍**于单腿,且随 N 对数增长。
现行门槛 z=1.0 是按**单腿**空间标的,搬到串关上等于把标准悄悄放松一半。
**这才是必须先测再上的理由。**

## 1. 候选腿(与 clv_ledger 同源,不另立口径)

一条候选腿 = (比赛, 玩法, 结果),满足:

- 有竞彩 SP > 1
- 有**捕获时刻** Pinnacle 三元组 → 去vig 得 `p_cap`(had 走 `_devig3`;
  hhad 走 `_hhad_cover_p` 用捕获时 1X2+O/U 反推)
- 有**收盘** Pinnacle 三元组 → 去vig 得 `p_close`(用于事后评估,**选择时不可见**)

```
cap_ev = p_cap   × SP − 1     ← 选择用(无前视)
clv    = p_close × SP − 1     ← 评估用
```

---

## 2. 配对宇宙(**主要杠杆,先锁死**)

一对 = 两条候选腿,必须同时满足:

| 约束 | 值 | 理由 |
|---|---|---|
| 同一投注日 | `match_date` 相同 | 竞彩串关在同一日内 |
| **不同比赛** | 两腿 `(date, home, away)` 不同 | 同场两腿互斥/强相关,竞彩本就不许 |
| **每腿单独下限** | `cap_ev ≥ FLOOR` | 保底 + 为未来的阈值规则留口(**不是**组合数杀手,见下) |
| **FLOOR = +0.02** | 见下 | |

**FLOOR = +2% 是在看任何结局之前定的**,理由只有两条,都与结局无关:
1. 它是单腿闸(5%)的**一半** —— 恰好允许「两条都不够、合起来够」这个本次要测的
   现象存在(2%+2% → 4.04% 仍不过闸;3%+3% → 6.09% 过闸),不会把要测的东西
   自己筛掉。
2. ~~它把组合数从 ~45,000 压到几十对,把诅咒从 4.6σ 拉回 ~3σ。~~
   **✗ 此条已作废(2026-07-25 同日更正,见 §7)。** 既然选择规则是 argmax,
   top-2 腿必然远在 +2% 之上 —— 下限把候选**对数**从几万砍到 9,却**一条都没改变
   被选中的那一对**。它管的是计数,不是选择。
   **保留它**的真实理由只剩两条:(a) 一个无害的保底,挡住「一条 +30% 配一条 −20%」
   这种病态组合;(b) 若 Phase 2 改用**阈值规则**(下注所有过闸的对,而非只下最好那一对),
   下限就会真正开始约束宇宙 —— 那时它是现成的。

⚠️ **FLOOR 不许在看过结局后调整**。若要改,视同新假设、重新计数。

## 3. 判闸与选择

- **配对闸** = `pair_ev ≥ 0.05` —— **与单腿闸同一个数**。
  这是刻意的:要测的正是「同一条 5% 线搬到更大的搜索空间上还成不成立」。
- **每个投注日只选一对**:`argmax pair_ev`(捕获时刻,无前视)。
  一天一对 = 与逐腿账本「每场选一腿」同精神,避免同日多对互相相关地灌进样本。

```
pair_ev  = (1+cap_ev₁)(1+cap_ev₂) − 1
pair_clv = (1+clv₁)(1+clv₂) − 1
```

（两腿来自不同比赛,按收盘概率独立 —— 这正是竞彩自己相乘时的假设。）

## 4. 结局(先声明,后测)

**主要结局**:选中对的**平均 pair_clv**。
> 正 ⇒ 配对闸在真实竞彩人口上找到了真边;
> 零/负 ⇒ 它只是把噪声组合得更好看。

**次要结局 A(②的前提检验)**:选中对两腿 `clv` 的**相关系数**。
> ≈0 ⇒ 分散化成立,σ 平方和加;
> 显著 >0 ⇒ 好处归零,②那套论证作废。

**次要结局 B(多重性记账)**:每日候选对数 `n_pairs`。
用于事后算所需 z = √(2 ln n_pairs),与实际用的 z=1.0 对照。

**对照组**:同期**全部**合法对的平均 pair_clv(不筛闸)。
选中 vs 全体 的差 = 选择规则的真实贡献(逐腿版这个差是 **+11.2pp**:
−11.3% → −0.1%)。

## 6. 已知局限(诚实边界)

1. **捕获时刻 Pinnacle 不等于下注时刻**。`psc_*` 是竞彩 SP 被捕获那一刻的
   Pinnacle,与你真正下单的时刻有冻结缺口(σ_P(h)=0.79pp·h^0.31)。本测量因此
   偏保守/带噪,不是精确复刻。
2. **hhad 反推**依赖捕获时的 O/U;旧行缺 O/U 时退化用默认总进球(与 clv_ledger
   同一局限,不新增)。
3. **δ 校准**:−1/+1 线有 C1 修正,**±2 线没有**(`c1_leg_lower_bounds` 对
   line∉{−1,+1} 返回 se=0)。−2 让胜实测高估 5~8pp 且落甜区 —— 配对若选中这类腿,
   pair_ev 会继承那个虚高。本期**不排除**它们(排除会改变宇宙定义),但报告里
   单列 ±2 腿占比,供 Phase 2 判断。
4. **单关可得性未纳入宇宙**:本期测的是「配对这个数学对象值不值」,不是
   「今晚该买哪对」。可得性过滤留给 Phase 2。

## 7. 更正记录(2026-07-25,与预注册同日)

写完本文档当天做了一个蒙特卡洛(参数取自实盘 1,629 条腿:真实 EV ~ N(−11.3%, 8.2%)),
它推翻了 §0/§2 里两个说法。**原文用删除线保留,不抹掉** —— 错误的推理过程本身是资产。

**更正 A · 搜索空间不是 N²。**
`(1+a)(1+b)` 对 a、b 都单调递增 ⇒ **配对 argmax 必然就是观测最高的那两条腿**。
枚举全部 1,770 对与直接取 top-2 得到完全相同的结果。所以搜索空间是 **N 条腿**,
不是 N² 对,「45,000 / 4.6σ」从根上算错了。

**更正 B · 下限对 argmax 不起作用。** 见 §2 修订。

**由此产生一条新的、可证伪的预注册预测**(这比原文更强 —— 原文只有定性担忧):

> **P1**:选中对的虚高(pair_EV − pair_CLV)≈ **2 ×** 单腿虚高,
> 且两者都随 ln N 增长。模拟给出的点值:N=300、σ_obs=5% 时
> 单腿 +7.5pp、二串 +15.7pp(倍数 2.0)。
>
> 实盘若测出倍数显著 **< 1.5** 或 **> 3**,说明模型漏了机制,回来改模型 —— 不改数据。

**一个反直觉的副产物**(拨 ρ 得到):全场误差相关**越高**,虚高**越小**
(ρ=0.9 时从 15.7pp 掉到 2.4pp)—— 共同分量对所有腿一视同仁、不提供区分度,
选择只能在剩下的独立噪声里挑。但代价是它把「挑错腿」的风险换成了
「**挑错晚上**」:某些晚上所有腿一起显得好看,而你会系统性地在那种晚上下注。

## 8. 历史回测可行性(2026-07-25 盘点)

原计划是「前向攒到 N≥30 投注日」。盘完历史资产发现**不必等**:

| | |
|---|---|
| `jingcai_odds_history` | 7,796 场(had)/ 8,163 场(hhad)· 892 个投注日 · 2021-07 → 2025-07 |
| 比分 | **100% 齐全**(表内自带 `home_goals`/`away_goals`,不需外接) |
| `single_available` | **已记录**:826/7,796 = **10.6%** 可单关(与前向 17% 同量级,互相印证) |
| 变盘序列 | 每场 **8.7 次**记录 —— 前向路径没有的东西 |
| 皇冠锚下可 join | **2,117 场 · 213 个投注日,其中 189 天有 ≥2 场** |

**189 个可组串的投注日 = 本预注册要求的 6 倍。**

⚠️ 三条前置条件,缺一不可:
1. **锚是皇冠不是 Pinnacle**(Pinnacle 只 join 上 394 场/73 天)。皇冠去vig 有实测
   **−1.5pp 平局偏差**,回测前必须先去偏,否则平局腿系统性虚高。
2. **回测无前视只能靠纪律**:选择只准用 `update_dt ≤ 决策时刻` 的 SP。
   好在变盘序列每场 8.7 次,这个约束可执行 —— 甚至比前向数据更细。
3. **本文档 §7 的更正必须先落地**(已落地)。拿一个已知有错的设计去消耗 189 天
   唯一一次干净的样本,不划算。
