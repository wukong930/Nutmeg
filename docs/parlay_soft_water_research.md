# 串关研究备忘:机器就绪,等秋天的信号

**状态:🟡 等数据(data-gated)** · 记于 2026-06-19,补 §5「历史回填已排除」2026-06-22、§6「盘口路径/冻结缺口」+ §7「玩法维度」2026-06-23 · **下次起点 = 欧洲联赛复赛(~8 月)**

> **一句话**:可信赖串关的「组合机器」已造好并校准;但**现在能测的市场(锐利 WC + 薄芬超)里没有任何 +EV 腿**,而软水论真正的目标市场(13 个受训欧洲联赛)6 月全休。
> **当前样本不足以证明软水有或没有 —— 等秋天。**

---

## 1. 问题
串关是主流玩法。「怎么组合一注可信赖的串关」= 怎么找到一组**每条都 +EV** 的腿,再正确地组合 + 定注。
分解:**上游 · 找 +EV 腿(难的 80%)** + **下游 · 组合决策(易的 20%,可建)**。

## 2. 已证明 / 已造好的(机器 ✅)

**a) 组合数学(蒙特卡洛,已解):**
- **同场关联**:捷克「主胜 + 大 2.5」真实联合 **31.2%** vs 天真乘法 25.5%(差 **+5.7pp**)→ 同场腿必须抽联合比分,不能相乘。
- **跨场独立**:捷克主 + 瑞士主,模拟 = 乘积(差 0.01pp)→ 标准竞彩串关(跨场)用乘法**精确**,不用模拟。
- **资金 / 破产**:整季打 N 注 → 终值分布 + 破产概率(公式只给期望,模拟给分布)。

**b) 三条铁律(都从上面算出,非观点):**
1. 串关只复利、不创造边:`EV_串 = ∏(1 + EV_腿) − 1`。一条 −EV 腿乘进去拖垮整串。
2. **可信赖串关 = 每条腿单独 +EV。**
3. 独立 +EV 腿:**单关 ≫ 串关**(Kelly 增长 —— 同样 4 腿拆成单关打长期快 ~3 倍)。串关只两个正当理由:① 竞彩单关不可投(结构性逼你串);② 娱乐(非增长最优)。

**c) 选腿机制(一致可信):** 捕获时 EV 单调预测实现 CLV(−10%→−17% / −3~0%→−0.9%)→ 下注时看到的边 ≈ 兑现的边,无前视惊吓。**但它不制造边 —— 水位决定一切。**

## 3. 已测量的(信号 —— 现在没有 ❌)
2026-06,33 条有 Pinnacle 捕获快照的腿:
- 捕获 EV 中位 **−9.7%**,**最好 −0.0%(打平),+EV 0 条**;实现 CLV ~**−10%**。
- **WC 21 腿(−10.4%) ≈ 芬超等 12 腿(−10.8%)** → 「软水在次级在季联赛、不在 WC」假设**被证伪**(原本这么赌)。
- 抽水墙 **−9 ~ −11%** 在两个市场都成立。

## 4. 为什么这不算定论(关键 ⚠️)
**世界杯和芬超的比赛不足以证明任何事:**
- **WC 国家队** = 全世界最锐利、最有效的市场(人人都对世界杯 sharp);
- **芬超** = 薄盘 + 样本仅 12 腿,够不上一个真测试;
- 软水论针对的 **13 个受训欧洲联赛**(EPL/西甲… 中国公众钱重、模型有边)**6 月全休,根本不在样本里**。

→ 现在能测的全是「错的市场」。**论点 data-gated 在秋天**;「没找到边」≠「没有边」。

## 5. 历史回填已排除 —— 不能跳过等待(2026-06-22 探到底)

**问的问题:** 与其等秋天,能不能现在回填一整年历史 CLV 来测软水?**不能 —— 卡在价格侧。**

CLV 两半的历史可得性:
- **Pinnacle 收盘**(公允 P 侧)← Odds API 历史快照,可回溯多年 ✓;
- **竞彩 SP**(价格侧 = 你下注那个价)← **瓶颈。**

**两个独立来源都证实:历史竞彩让球 SP 拿不到。**
- **sporttery 官方结果端点**(`getUniformMatchResultV1`,带 `matchPage` 参数):给**胜平负(1X2)SP**,回溯一年+;但**只给 1X2** —— 让球(hhad)SP 字段不存在(计算器端点有让球、仅当前盘,settle 后不给)。
- **500 彩票网**(`www.500.com/static/public/jczq/xml/hisdata/<年>/<月日>/`,免费、回溯到 2013):给博彩盘口(皇冠/澳门/Bet365…,实测**收盘级**,皇冠去vig ≈ Pinnacle 收盘 1~4pp),但**竞彩官方 SP 字段 `plnspf` 全空**(估计 2015 网售禁令后停存)。
- → **竞彩让球 SP 历史公开数据里不存在;价格侧只能向前**(`jingcai_sp`,~5 月底起,哨兵护着)。

**能回填的那半(1X2)已实测,仍是墙:** 2025-11-08 在季英超/西甲/德甲/意甲 5 场(竞彩 1X2 SP × Pinnacle 历史收盘)→ 15 腿,中位 EV **−11.3%**,最好 −0.4%,**0 条 +EV**,竞彩 1X2 vig 恒 12.9%。**在季受训联赛的 1X2 主盘 = 同一面 −11% 墙。** 能回填的无边、还不是你玩法;有可能软的(让球)回填不了。

**唯一完整回填成功的一注 = 神户案例(教科书「赢 ≠ +EV」):**
> 2026-05-30 J 联赛 神户胜利船 vs 鹿岛鹿角,主让胜(-1)竞彩 SP **5.5**,**命中、赢钱**。因为你**手记了竞彩 SP**,这注 CLV 能完整回填:Odds API 恢复 Pinnacle 收盘 → 反推让球公允 → **CLV ≈ −0.2%**(竞彩定得**几乎完全公允**)。
> **它赢了,但 −0.2% 说明是方差、不是边。** 印证两点:① 捕获时 EV ≈ 兑现 CLV(无前视惊吓);② 单注命中完全可以是公允/−EV 的 —— **别把「赢了」当「有边」**。
> 而它**只在「你手记了竞彩 SP」时才回填得了**(没有任何历史源能补出这个让球 SP)—— 反过来坐实了上面的瓶颈。

**副产品(底牌):** 500 = 免费 13 年**收盘级亚洲盘口档案**(皇冠/澳门 + 直接让球线)。是**公允 P / benchmark 侧**的大杀器(秋天有向前竞彩让球 SP 后,可直接算让球 CLV、省 Odds API 配额、免 DC 反推),**但不是价格侧**,单独解不开软水。详见记忆 `500-historical-odds-archive`。

## 6. 盘口路径 / 冻结缺口:有价值的是「缝」、不是「线」(2026-06-23 判断 + 已建初/终捕获)

**问的:** 竞彩盘口从开盘(11:00 开售)到闭盘(~23:00 冻结)这一路的变化路径,有研究价值吗?

**关键认知:竞彩的移动 ≈ Pinnacle 移动的「滞后劣化影子」。** 竞彩 SP 不是 sharp 资金推的市场价,是体彩**行政设定** —— 盯亚盘/sharp 共识走 + 加水(margin 108-114%)+ 按国内盘口流量微调。所以它开→闭的移动**大部分是在追 Pinnacle**(更慢、更糙、盖了层中国散户流);而 Pinnacle 的开→闭路径我们已有(`odds_snapshots` 线史)。→ **竞彩路径里唯一独家的信息 = 它偏离 Pinnacle 路径的那部分(缝),不是路径形状本身。**

**三个角度,价值排序:**

**① 冻结缺口(最高价值 · 最便宜 · 数据已有)★** —— 竞彩 ~23:00 冻死,Pinnacle 继续动到开球。软水 EV 就活在「竞彩冻结 vs Pinnacle 还在动」这条缝里(`jingcai_sp.py` 文件头即此论)。**可证伪结构假设:EV ∝ 冻结→开球的小时数** —— 深夜欧洲场(冻结后还有 3-4h Pinnacle 漂移)软水潜力更大。**用已有数据就能测**:终盘 `jc_*` + Pinnacle 收盘 + `kickoff_utc`。新加的初盘 `jc_open_*` 再答一个**下注时机**问题:初盘 vs 终盘,哪个对 Pinnacle 更划算。

**② 反向散户(可测 · 数据门 · 信号被稀释)** —— 竞彩开→闭往哪边缩,可能 = 国内散户超买的那边 → 反着打。路径给方向。坑:竞彩移动很大程度是「盯 sharp 校准」而非「纯散户流」,反向信号被冲淡,得大样本才能从噪声里分出。

**③ 路径形状当模型特征(低价值)** —— 「早动/晚动/反复」这些轨迹细节,**净位移(开→闭 delta)通常吃掉绝大部分信息**;且它 ≈ Pinnacle 路径的劣化版,模型里已有博彩盘 movement 特征(W5 `market_dynamics`)。增量薄。

**数据状态(已建):** 现在留**两个点** —— 初盘(11:05 `com.nutmeg.sporttery_open` cron → `jc_open_*`,set-once)+ 终盘(23:15 `sporttery_ingest` → `jc_*`);外加 Pinnacle 连续线史(`odds_snapshots`)。**没有**密集的竞彩日内轨迹。

**裁决 + 纪律:**
- **不建密采竞彩日内轨迹**(每 2h 抓一次那种)—— 角度③已说净位移就够,密采是 Okooo 式「投入大产出薄」的坑。**初/终两点是对的粒度。**
- **秋天该跑的(机器已就位:`nutmeg-handicap-triples` + 初/终捕获):** 最便宜的两个 —— ❶「冻结缺口 EV vs 冻结→开球时长」❷「初盘 vs 终盘 EV」。到点喂受训联赛数据即出。**❶ 已展开成可证伪测试卡 `docs/freeze_gap_test_card.md`(深夜欧洲场缝最大),实证后盾见 `docs/sharp_money_market_microstructure.md` §4:Kaunitz 2017 实测开球前 1–5h 的盘 +9.9% vs 收盘 +3.5% —— edge 在临近收盘几小时最肥,正是冻结缺口活的地方。**
- 同 §4:全是前向数据门。**别为「路径好看」提前建东西。**

## 7. 玩法维度:比分/总进球做了、半全场搁置(2026-06-23 判断 + 已建捕获)

**问的:** 我们能从竞彩官方拿到 1X2/让球之外的玩法 SP,该不该扩充?哪些?

**竞彩同一端点免费给四种玩法 SP**(同 `getMatchCalculatorV1` 的 poolCode):胜平负 `had`、让球 `hhad`、**比分 `crs`(31 个结果)**、**总进球 `ttg`(8 个)**、**半全场 `hafu`(9 个)**。问题不是「能不能拿」(都能,已实测 22 场全回),是「值不值得为它算 EV」—— 取决于**有没有现成的公允 P**。

**关键认知:比分/总进球的公允 P 是免费的,半全场不是。**
- **比分 = DC 比分网格的一个格;总进球 = 网格的一条对角线和。** 我们的 `market_handicap.fit_lambdas`/`score_grid` 早已从 Pinnacle〔1X2 + O/U〕反推出完整比分分布(让球就是这么来的)。所以 `q(比分/总进球)` **零新模型、零新数据**就能算 —— 与让球共用同一张网格、同一个 Pinnacle 先验。
- **半全场需要一个半场模型**(HT 结果的 P),全场比分网格**给不出**。半场模型要半场 Pinnacle 盘做先验 —— 而 Odds API 实测(2026-06-23):1st-half 市场(`h2h_h1`/`totals_h1`)对 soccer **存在**,但 Pinnacle **只给顶级联赛**(EPL)开半场盘,WC / 意甲 / 美洲杯 / 北欧 = **0 覆盖**;`halftime_fulltime` 市场只有软书报价(无 sharp 锚)。→ **我们在意的盘上没有半场公允 P,半全场比其余玩法的数据门更死。**

**为什么扩(对软水有意义):** 文献一致认为软书**最软在冷门玩法** —— 散户重押热门比分(2:1/1:0)、方差大、是娱乐钱的池子。竞彩软水若存在,比分/总进球是头号嫌疑;且它们**赔率高 → 是串关友好的腿**。这正是 §1 上游「找 +EV 腿」该撒网的地方。

**已建(机器):** `jingcai_exotic.py` —— 长格式表 `jingcai_exotic_sp`(一行一个结果,PK `(date,home,away,market,outcome)`),`record_exotic_sp` 捕获(latest=终盘,settle-later 不被覆盖)+ `settle_exotic_sp`(命中腿 hit=1、其余 0,超网格高比分归 胜/平/负其他)。`nutmeg-ingest-sporttery --exotics` 开关拉 `crs,ttg`。**捕获 + 结算 only,EV 不在这层算(秋天)** —— 同 §4/§8 全是前向数据门。

**裁决 + 纪律:**
- **比分/总进球:做(已做)。** 复用现成网格,零新基建,正是该薅的便宜 —— 与 §6「初/终两点是对的粒度」同理:用已有的 Pinnacle 先验,别造新东西。
- **半全场:搁置。** 需要一整个半场模型 + 我们取不到的半场 sharp 盘 = Okooo/Betfair 式「投入大、产出不确定」的坑。**不为它建半场模型**,直到顶级联赛之外有了半场 Pinnacle 覆盖(目前无)。
- **前向累积要授权:** `--exotics` 开关已就绪,但把它接进 23:15 终盘 cron(让它每天攒)是**改 cron,需显式授权**;现仅手动/按需跑。
- **秋天该跑的(机器已就位):** 把比分/总进球 SP × DC 网格 P 拉进 §3 同一套 EV 测量,看冷门玩法的 vig 墙是否比 1X2 主盘(−11%)薄。**但权重排序要按 `docs/score_grid_cell_calibration.md` 的裁决:聚合/「其他」桶 ≫ 总进球 ≫ 具体比分单格 —— 同行评议一致「反推网格单格不可信」(精确比分模型和市场都无效、博彩比分抽水 ~12%),且 DC 修正对总进球(O/U 线)等于没做。比分单格 EV 当最不可信的一类,预期它是最厚的 vig 墙。**
