## §1 🚨 我原本的三条说法,全部被推翻

**这一节是本文档最有价值的部分。** 三条都是我在讨论中作为「反对 owner 判断」的
证据讲出去的,三条都错。

### ① 「模型腿 ≡ 市场腿,corr=0.990 ⇒ 调权重改不动选择」→ **反了**

那不是共线性证据,是**代码写死的恒等式**。
`dashboard.html:5197-5202` 在 `mode !== 'cup'` 时:

```js
const mkt   = mode === 'cup' ? null : _mktP(pr);
const p1x2  = mode === 'cup' ? { H: pr.p_home_1x2, ... } : mkt;   // ← 直接赋成市场 P
```

⇒ **标准模式的 1X2 腿从 2026-08-07 起根本不读模型 P**,两臂都是 Pinnacle WPO。
而且那个窗口里 `board_leg_snapshot` 标准模式的 2,196 条腿 **jc_sp 全为 NULL** ——
连一条可下注腿都没有,**压根不存在 argmax**。

**在模型 P 仍然驱动选腿的路径上换 P 源,结果完全相反**
(`/recommend` → `combo/selections.py`,13 个训练联赛走模型网格;
N=6,516 场 / 871 比赛日 / 10 联赛 / 2021-07-31→2026-01-14,真实竞彩终盘 SP,比分硬闸):

| | 点估 EV 口径 | 下界 evLo 口径 |
|---|---:|---:|
| argmax 翻转 | **2,411 / 6,516 = 37.0%** | **2,645 / 6,516 = 40.6%** |
| 其中结算结果不同 | 976(15.0%) | 1,282(19.7%) |
| 空包弹基线(两臂同源) | **0 / 7,005 = 0.00%** | — |
| 样本外留出窗(N=690,25-10→26-01) | 38.1% | 41.4% |

另有 **6.7%** 的比赛,换 P 源改变的是「**有没有注可下**」
(404 场只有模型 P 给出可投注腿、34 场只有市场 P 给出)。

### ② 「corr=0.99 ⇒ 两个 P 一样」→ **混池假象,而且偏差有方向**

三腿混池 corr=0.9935(N=91,332 腿)。**分 P 桶后**:

```
P<0.1  0.674 │ [0.1,0.2) 0.825 │ [0.2,0.3) 0.906 │ [0.3,0.4) 0.927
[0.4,0.5) 0.875 │ [0.5,0.6) 0.811 │ [0.6,0.7) 0.730 │ P≥0.7 0.866
```

有符号偏差**单调**:P<0.1 的 **+2.18pp** → P≥0.8 的 **−6.40pp**(N=839)——
模型系统性把大热门往回缩。翻转率随热门程度从 [0.3,0.4) 的 **21.0%**
升到 [0.8,0.9) 的 **83.0%**(N=94)。**共线性正好在热门腿最贵的地方最先塌。**

⭐ 机制:每场最优腿对次优腿的 EV 领先中位只有 **2.39pp**(四分位 [0.94, 5.02]),
而换源造成的单腿位移中位 **2.77pp**、p90 **9.12pp**(N=21,015 腿)——
**扰动 ≥ 领先优势 ⇒ 大面积翻转是结构性必然。**
「模型特征 67.5%/82.6% 来自 Pinnacle」是实测事实(CatBoost PredictionValuesChange),
但**高特征共享 ≠ 决策不变**。

线上独立交叉验证(`board_leg_snapshot` 标准模式 1X2 腿,N=549 腿/42 场/8 联赛):
|p_model − p_market| 中位 **1.60pp**、p95 5.13pp、max 9.69pp;
**64.8% 的腿超过 δ₁ₓ₂ 那 1.16pp 收缩量** —— 线上分歧比回放**更大**。

📌 成文反例早就在仓里:`routes.py:2419-2422` 把 JPN_J1 移出 `_SP_CALC_LEAGUES`,
原文理由是模型与 sharp 线「diverges ~13pp」。实测 J1 max|Δ|=**14.00pp**(N=4,503),
翻转率全场最高(48.1% / 57.3%);即便 EPL 也有 max|Δ|=15.07pp。

### ③ 「热门吃 60% 抽水 ⇒ 买热门贵 3 倍」→ **零假设错 + 单位错**

**零假设错**:正确的 null 不是 33/33/33,是「抽水正比于公允概率」——
热门腿本来就占 52–53% 的概率质量。真正属于竞彩**选择**的偏离只有
**+0.56pp**(聚类自举 95%CI [+0.32, +0.79],N=392 场 / 1,176 腿),
比我们**最小**的逐腿常数(δ₁ₓ₂ 的 1.16pp)还小。
同一批腿上它只翻转 **1** 条判闸,δ₁ₓ₂ 翻转 **5** 条。

**单位错**:7.14pp vs 2.71pp 是**加价**,要乘 SP 才是每元成本:
7.14×1.72 ≈ **12.3%** vs 2.71×4.8 ≈ **13.0%**,正好抵消。
实测三档 ROI −12.11 / −10.14 / −12.69%,热门−冷门 Δ=**+0.59pp,p≈0.82**
(N=7,065 场 / 21,195 腿)。

**而且 `EV ≡ −vig×SP` 是恒等式**:R²(腿位 → 逐腿 vig)=**0.517**,
但 R²(腿位 → 逐腿 **EV**)=**0.034**。价格侧的分配只是 EV 的重新参数化。

### ④ 顺带:「让球占池 43%」「1X2↔让球才是真分界」也都不对

让球是**多数不是少数**:五年档案 51.2%(18,003 vs 17,167 场)、
`jingcai_sp` 51.6%、线上盘面 50.0%;27 场只卖让球、**0 场只卖 1X2**。

两族覆盖缺口**逐 pp 相同**(同一份 football-data 锚、同一把 join:

⇒ 0 覆盖对两族同时成立。

而 `market_handicap.py:361-374` 的 δ 干的就是 `ph -= shift; pd_ += shift`

## §3 ⭐ 三个结构性发现(比排序本身更重要)

### ① 闸落在第 99.66 百分位 —— 测量分辨率被人口形状锁死

```
evLo 中位 −14.93%(N=24,606 腿,皇冠锚)/ −15.21pp(N=39,096 腿,fd Pinnacle 锚)
+5% 闸 → 第 99.66 百分位
闸边 ±1pp 内只有 43 / 39,096 条腿 = 0.110%
```

⇒ **任何推力 < 2pp 的常数,在「过不过闸」这个指标上必然显示「几乎不变」。**
这不是常数不重要,是**这个指标测不动**。用它下「某常数不重要」的结论会系统性出错。

### ② 不存在有特殊杠杆的因子,只有「它能推多少 pp」

churn% ÷ med|ΔevLo| 落在 **20–56% churn/pp** 的窄带:

```
开售价 56.0 · 抽水→5% 54.4 · 下界全关 47.7 · δ×1.5 22.2 · 抽水均分 20.6
```

⇒ **因子排序 ≡ 位移量排序。** 原因见 ①:闸在 99.66 百分位,那里密度极薄且近乎均匀,
任何位移都按线性搬运腿。**所以别再找「哪个旋钮特别灵」——只有「哪个旋钮推得远」。**

### ③ 腿的「身份」只值 9% 的方差

决策变量 d = ln P − ln q(判闸 ⟺ d ≥ 0.1703,即我们的 P 要比竞彩隐含 P 高 **18.6%**)
的方差分解(N=24,606):

| 来源 | 解释方差 |
|---|---:|
| 腿位热度 | 8.68% |
| 市场(1X2 vs 让球) | 0.54% |
| 联赛(39 个) | 0.16% |
| 三者全交互 | 20.01% |
| **残差(逐场特异的价格分歧)** | **79.99%** |

⇒ **这是对 owner 那个问题最直接的回答:腿的身份只解释 9% 的方差。**

## §7 诚实边界(别读成结论的)

- **所有 ROI 都读不出来**,除 δ₋₁×2 那一条。基线过闸腿历史 N=59 / N=126、实盘 N=8;
  六条腿分开后有四条 N=7~16(让负 +13.0%±37.8pp、让平 −32.1%±67.9pp)。
  合计 126 条过闸腿 −6.4%±16.5pp vs 基准 −12~−13%,**z<0.5**,
  且 SE **未按比赛日聚类** ⇒ 真实 SE 更大。
- **churn% 不可靠**:分母 8 或 126,连「换个 sharp 锚、P 只动 0.56pp」都能报 200%。
  排序以 med|ΔevLo| × 覆盖为准。
- **两个人口谁也不代表实盘**:历史人口是收盘 SP × 收盘 Pinnacle、锚死于 2026-01-14、
  只有 9 个欧洲联赛;今日人口 408 场大半是世界杯/北欧/韩职,那里 δ 和 `ONEX_SE` 全是借来的。
- **模型 P vs 市场 P 在可投注人口上没测出来**:只有 20/392 场(5.1%)有独立模型 P,
  `board_leg_snapshot` 里 186 条竞彩上架的 had 腿 `p_market` 非空 **0 条**。
  ⚠️ 这是夏季的结构性空洞 —— **是不是也是采集侧的结构性缺口,由后续预检回答**。
- **30,444 场是 in-sample**(artifact 训练截止 2026-06-01,n_train=29,347);
  缓解证据是 VAL 切片 1,097 场给 97.27% ≈ 全样本 97.25%,
  但**不存在真正的大样本样本外**,因为 PSC 在 2026-01-14 断供。
- **配对 ΔROI(模型腿−市场腿)点估 +2.19pp±1.71、下界口径 +4.42pp±1.63(t=2.71,
  比赛日聚类)不是预注册检验**,只用来说明「差异有后果」,⛔ 不可读成「模型更好」。
- **没测**:串关票层(∏(1+evLo))的翻转、腿间相关性、结算侧、
  竞彩 SP 在「我们看到它」到「封盘」之间的移动(测的是开售→封盘全程)、
  让球盘的实际过闸分布。

### ⭐ 一次自己抓到的空包弹

逐常数扫描曾把 `_C1_SE_K` 报成 **0.0% churn** —— 因为
`def c1_leg_lower_bounds(..., *, k: float = _C1_SE_K)` 是 **def 期绑定**的默认参数,
改模块属性无效。打了一发必红的断言才发现;**显式传 k 后真值 k=1.0 → 62.7%**。

同族的另两个 0.0%(`_UNCAL_SE`、`_C2_*`)逐一查过作用人口(1.06% / 3.16%),
确认是「人口小」不是「没效应」。

⇒ **通用教训:monkeypatch 模块属性对「def 期绑定的默认参数」无效,
而它的失败形态恰好是「一切正常,效应为零」。**
