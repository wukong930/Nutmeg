# 竞彩 逐路 vig 分解 — 水不是平均倒的

_2026-07-06 · 探索方向 #1 · 只读测量,赛前可测,零 API · 工具 `nutmeg-vig-shape`_

## 问题

竞彩整体 vig ~12.9% 是已知的。没人问过:这层水在 **主/平/客** 三路上是**平均**
分布,还是**偏袒**——厚压在散户重仓那路、削薄人群回避那路?

**干净的零假设:** 比例(basic)定价下,每条腿的 per-leg margin **相等**。证明——
若 `SP_i = 1/(P_i·(1+OR))`,则 `P_i·SP_i = 1/(1+OR)` 对所有 i 恒定,故逐腿
`vig_i = 1 − P_i·SP_i = OR/(1+OR)` 全等。**任何偏离等值 = 竞彩在不均地铺水**,而
且这是**赛前可观测**的——若偏袒方向跟散户票走,软腿(薄水腿)从价格形状本身就能定位,
不用等结果。

口径:`P_i` = Pinnacle WPO 去vig 公允概率,`SP_i` = 竞彩 SP,`vig_i = 1 − P_i·SP_i`
= 下注者逐腿 −EV。语料:`jingcai_vote` + `jingcai_sp` 里同时带竞彩 SP 与 Pinnacle 的行。

## 结果(N=55 场,含 36 场带散户票 / 108 条带票腿;发现期夏季样本)

平均总 overround **13.0%**(印证已知 ~12.9%)。

**① 竞彩不是比例定价 —— 铁证。** 场内 vig 极差(max−min)均值 **12.0pp**;比例定价下
应为 0。竞彩**明确在偏袒某路**。

**② vig 偏向热门腿。** sharp 热门那路 vig **+12.7%** vs 非热门 **+10.1%**(差 +2.6pp)——
「押热门」本身更贵。

**③ 剃刀:vig 随散户票单调上升。**

| 档 | 均票 | 均 vig |
|---|---|---|
| 低票 | 15% | +8.7% |
| 中票 | 29% | +9.6% |
| 高票 | 56% | **+13.6%** |

竞彩在人群回避的腿上只收 8.7% 水,在人群涌入的腿上收 13.6% —— **约 5pp 摆幅,单调**。

**④ 控制热门度(只看非热门腿,剥离「热门本就贵」混淆):**

| 档 | 均票 | 均 vig |
|---|---|---|
| 低票 | 12% | +8.0% |
| 中票 | 22% | +7.8% |
| 高票 | 33% | **+13.1%** |

非热门腿里,低/中票**基本持平 ~8%**,只有**高票非热门腿跳到 +13.1%**。所以剃刀**不是**
平滑单调,是**阈值型**:一条非热门腿只有被散户高度关注(33% 票,对冷门方已很高)时,
竞彩才把水加厚。低/中票冷门腿是真正的**薄水区(~8%)**。

## 裁决

1. **竞彩绝非比例定价**(极差 12pp)—— 新知,首次量化。
2. **vig 偏向散户注意力,且超出单纯热门度**(④ 高票非热门腿仍 +13.1%)—— 剃刀真实,
   但**阈值型**(高关注才触发),非平滑单调。
3. **最薄水区 = 低/中票非热门腿(~8% vs 全场均 13%)** —— 相对软水集中处,**赛前可定位**。
4. **但即便最软腿也仍是正 vig(~8%)** —— 这只**定位软腿位置、压缩搜索空间**,不凭空造
   +EV。要翻正,还需竞彩把该腿削过头(压到公允 P 之下),或叠加冻结缺口 / sharp 背离。
   本样本薄到 8%,**没**过零。

## 边界

- N=55(带票 36),发现期夏季(世界杯 + 友谊 + 零星联赛),**非受训面秋季总体**;描述性
  均值,未做聚类 t / 显著性。剃刀的阈值形态尤其需要更大 N 确认。
- P = 捕获时 Pinnacle(非保证收盘);vig 形状对此不敏感(测的是竞彩相对 sharp 的偏袒),但
  绝对 vig 水平不代表收盘水平。
- **探索性,不动钱。** 「软腿在低/中票非热门侧」是假设,秋季须进预注册(仿 S2/S6)+ 过
  CLV 闸门才可能影响下注。

## 与既有测量的关系

这是投注量研究(S2,散户票 × 结果)的**供给侧孪生**:S2 看散户票**跟结果**的关系(需求→
真值),本测看竞彩**怎么给散户票定价**(需求→供给的 vig 响应)。两者交点:若④的薄水区
(低/中票非热门腿)正是 S2 里 CLV 转正的地方,则「反散户」策略有了**赛前可执行的定位器**
——不用等结果就知道往哪看。这正是「把解读盘口做得更深」:读的是水的**形状**,不是大小。
